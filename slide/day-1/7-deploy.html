CHAPTER 7 · 배포

자기소개 페이지를 세상에 공개

챕터 4에서 만든 자기소개 페이지는 아직 내 컴퓨터 안에만 있습니다. GitHub와 Vercel로 인터넷에 올려, 링크 하나로 누구에게나 공유합니다 — 전부 무료.

5단계
0원비용
1링크로 공유
WHY · 왜 배포하나

내 컴퓨터 속 파일 → 전 세계 누구나

지금까지는

  • about.html은 내 컴퓨터에만 존재
  • 남에게 보여주려면 파일을 직접 전달해야 함
  • 휴대폰·다른 PC에서는 열 수 없음

배포하면

  • 인터넷 주소가 생김 — 내이름.vercel.app
  • 링크만 보내면 누구나 접속
  • 휴대폰에서도 똑같이 열림

Vercel은 HTML·CSS 같은 정적 사이트를 무료로 호스팅합니다. GitHub에 코드를 올려두면 Vercel이 자동으로 가져가 배포합니다.

STEP 1 · GitHub 저장소

자기소개 폴더를 저장소로

GitHub에서 — 새 저장소

  1. github.com 우측 상단 + → New repository
  2. 이름 입력 (예: my-intro) — 영문·하이픈
  3. Public 선택 → Create repository
  4. 다음 화면의 주소(...git)를 복사해 둠
PowerShell — 자기소개 폴더
# 챕터 5에서 이미 했으면 생략PS> git initPS> git add .PS> git commit -m "자기소개 페이지"

저장소(repository) = GitHub에 올린 프로젝트 폴더 한 칸. 자기소개 페이지 전용으로 하나 만듭니다.

STEP 2 · push

내 코드를 GitHub로 올리기

push가 하는 일

  • 지금까지 commit은 내 컴퓨터 안 저장
  • push = 그 커밋을 GitHub(원격)으로
  • 한 번 연결하면 다음부턴 git push만
PowerShell — 원격 연결 + push
# 복사해둔 저장소 주소를 연결PS> git remote add origin https://github.com/...gitPS> git branch -M mainPS> git push -u origin main ✓ GitHub에 업로드 완료

처음 push할 때 GitHub 로그인 창이 뜰 수 있습니다 — 브라우저에서 승인하면 끝. 막히면 Claude에게 에러를 그대로 붙여넣어 물어보세요.

STEP 3 · Vercel

Vercel — GitHub 계정으로 시작

1

vercel.com → Sign Up → "Continue with GitHub"

2

GitHub 권한 승인 (최초 1회)

3

Add New → Project → 방금 만든 my-intro 저장소 선택

4

설정은 건드리지 않고 Deploy 클릭

5

30초~1분 빌드 → 배포 완료 화면

자기소개 페이지는 HTML 한 장이라 별도 설정이 필요 없습니다 — Deploy만 누르면 됩니다.

STEP 4 · 도메인 공유

내이름.vercel.app
— 내 페이지 주소

배포가 끝나면 Vercel이 인터넷 주소를 발급합니다. 이 링크를 가진 사람은 누구나, 어디서나 내 자기소개 페이지를 볼 수 있습니다.

확인Vercel 화면의 Visit 버튼 → 내 페이지 열림
공유주소를 복사해 카카오톡 오픈채팅방에
테스트휴대폰으로 열어보기 — PC와 똑같이 보임
STEP 5 · 수정과 재배포

고치고 git push — 자동으로 갱신

PowerShell — 페이지 수정 후
# 자기소개 페이지를 고쳤다면PS> git add .PS> git commit -m "사진 추가"PS> git push Vercel이 push를 자동 감지 → 재배포 ✓ 같은 주소에 최신 내용 반영

한 번 연결해두면 — 같은 주소가 항상 최신입니다. git push 한 줄이면 몇 초 뒤 반영, 별도 업로드 작업이 없습니다.

## 6. Day 1 · 만남 (월)

### 이론 ① — AI 코딩의 흐름과 Claude Code의 자리 (90′)
- AI 코딩 60년 압축사: 1세대 보조 → 2세대 추천 → 3세대 실행자
- 코드 작성 주체 변화 그래프 (사람% / AI%)
- 정의 한 줄 "터미널에 사는 AI 에이전트"
- ChatGPT와의 3가지 차별점 (터미널 · 권한모델 · 컨텍스트 인식)
- Anthropic 출시 배경 / 에이전트 사이클 5단계
- **강사 라이브 시연**: Claude Code 단독 5–8분 (Todo 앱 → "다크모드로" → "삭제 기능 추가")

### 실습 ① — Windows 셋업 & 첫 실행 (75′)
- 렌탈 랩탑 점검 → Node.js · VS Code 확인
- `npm install -g @anthropic-ai/claude-code`
- 로그인 / API 키 / **Windows 환경변수 PATH** 등록
- `claude --version` 통과 확인
- 빈 폴더에서 `claude` 첫 실행 → "안녕" → `/exit` `/help`
- 자주 막히는 포인트 즉시 해소: 관리자 권한 cmd, npm 경로, SSL/회사망

### 이론 ② — 터미널 입문 + VS Code 통합 + 프롬프팅 (90′)
- GUI vs CLI 개념
- Windows 터미널 6 명령: `pwd` `cd` `ls` `mkdir` `cat` + `touch` 대용 `New-Item file.txt`
- cmd vs PowerShell 차이 짧게 (실행 정책 등)
- VS Code에서 터미널 띄우고 Claude Code 사용
- 좋은 프롬프트 = "**무엇을 / 어떻게 / 어떤 형태로**"
- 자주 쓰는 슬래시 미리보기 (`/help` `/clear` `/cost` `/model`)

### 실습 ② — 자기소개 워밍업 (105′)
- "나를 인터뷰해서 자기소개 대본 만들어줘" → 짧게 / 길게 / 허풍 / 겸손 / 공식적
- 자기소개 기반 HTML 한 페이지 → 브라우저 확인
- 디자인 톤 변형 (모던 / 밝게 / 엉뚱) → 점진적 구체화 경험
- 결과물 `Day1/` 폴더 보존 (이후 4일간 재활용)

## 7. Day 2 · 문법 (화)

### 이론 ① — Claude Code 4대 문법 깊게 (90′)
- `/` 슬래시 커맨드 카탈로그 (`/init` `/clear` `/cost` `/model` `/agents` `/help`)
- `@` 파일 · 폴더 · 심볼 멘션
- `!` Bash 실행 (세션 안에서)
- `#` CLAUDE.md 즉시 메모

### 실습 ① — 4문법 손풀이 (75′)
- `/`로 모델 바꿔보기
- `@`로 어제 만든 HTML 멘션해 분석 시키기
- `!`로 git 상태 보기
- `#`로 "한국어로 응답" 메모 추가

### 이론 ② — 모드 · 권한 · 비용 감각 (90′)
- 4 모드: Interactive / Auto / Plan / Bypass
- `Shift + Tab` 모드 전환 / `--dangerously-skip-permissions` 경고
- 권한 모델: "always allow 무지성 금지" 1줄 규칙
- 컨텍스트 윈도우 · 토큰 · `/cost` 습관
- "한 입 거리로 잘라 시키기" 원칙

### 실습 ② — 미션 분할 빌드 (105′)
- 미션 ① 가위바위보 CLI (뼈대→입력→기록 분할)
- 미션 ② 단위 변환기 (cm↔inch, kg↔lb)
- 미션 ③ 단어 빈도 분석기 (시간 남으면)
- 매 미션 끝마다 `/cost`

## 8. Day 3 · 협업 (수)

### 이론 ① — Plan Mode 깊게 (90′)
- 안전벨트로서의 Plan Mode (`Shift + Tab`)
- 계획 읽기 → 승인 · 수정 · 거절
- 써야 할 때 vs 굳이 안 써도 될 때

### 실습 ① — Plan Mode 손에 익히기 (75′)
- 오픈 텍스트 게임 다운로드 → Plan Mode로 **분석만** 시키기
- 체력 시스템 추가 (Plan 승인 후 실행)

### 이론 ② — CLAUDE.md + CoT + 컨텍스트 관리 (90′)
- CLAUDE.md 좋은 예 vs 나쁜 예 (200줄 룰)
- 계층: 프로젝트 / 유저(`~/.claude`) / 엔터프라이즈
- CoT 유도: `think` < `think hard` < `think harder` < `ultrathink`
- 메타 프롬프트 / 자기 검증 요구
- 세션 관리: `/clear` `/compact` `/resume` `--continue`

### 실습 ② — 내 CLAUDE.md + 복구 + 주제 결정 (105′)
- 일부러 망가뜨린 코드 복구 (에러 메시지를 그대로 전달)
- 내 프로젝트 폴더에 CLAUDE.md 15줄 이내 작성
- **미니프로젝트 주제 결정** (강사 1:1 난이도 조정)

## 9. Day 4 · 확장 (목)

> 5일 중 가장 빡빡한 날. 모든 핵심 확장 기능을 한 번씩 다 만져본다.

### 이론 ① — Sub-agents + MCP (90′)
- Sub-agents (`/agents`): 컨텍스트 분리, 역할별 위임, 모델 선택 (Haiku / Sonnet / Opus)
- MCP "Claude의 USB 포트": `claude mcp add` 흐름
- 안전 후보: Filesystem · GitHub · Slack
- 회사망 차단 시 우회 / 로컬 MCP

### 실습 ① — Sub-agent + MCP 직접 만들기 (75′)
- Sub-agent 1개 정의 (예: 테스트 작성 전담)
- MCP 1개 설치 · 연결 (Filesystem 또는 GitHub)

### 이론 ② — Hooks · 커스텀 슬래시 · Skills (90′)
- Hooks 이벤트 6종: PreToolUse / PostToolUse / Stop / UserPromptSubmit / Notification / SubagentStop
- 활용: 저장 시 lint, 커밋 전 테스트, 응답 끝 알림
- 커스텀 슬래시 `.claude/commands/*.md` (반복 프롬프트 템플릿화)
- 공식 Skills: PPTX · DOCX · XLSX · PDF (`anthropic/skills`)
- 헤드리스 `claude -p` — **자료에만 포함, 짧게 언급** ("있다는 것만 알아두세요")

### 실습 ② — 자동화 한 줄씩 (105′)
- Hook 1개 (저장 시 lint)
- 커스텀 슬래시 1개 (본인 반복 작업 템플릿)
- 공식 Skill로 PPTX 생성 (Day 1 자기소개 → 발표 슬라이드 변환)
- 미니프로젝트에 도구 1~2개 녹이기 시작

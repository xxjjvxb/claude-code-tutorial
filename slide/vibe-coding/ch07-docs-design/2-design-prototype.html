7장 · PROTOTYPE

프로토타입 — 머릿속 그림을 화면으로

완벽한 설계 대신, 되는지 빠르게 만들어 눈으로 보고 손으로 굴려보는 게 프로토타입입니다. 여기서는 Claude Design으로 — 디자인 지식 없이 말 몇 마디만으로 진짜처럼 보이는 화면을 만들어 봅니다.

WHAT · 프로토타입

프로토타입 — "빨리 만들어 본다"가 전부

완벽히 설계하고 만드는 대신, 되는지 확인할 만큼만 빠르게 만들어 보는 것. 말로 설명하면 열 번 헤맬 것을, 눈에 보이는 화면 하나가 단번에 정리해 줍니다.

먼저설명보다 — 보이는 화면이 먼저
가볍게틀리면 버리고 다시 만들면 됨
핵심빠른 피드백 — 완성도는 나중
TOOL · Claude Design

Claude Design — 말로 그리는 디자인 도구

한 줄로

claude.ai의 디자인 도구. 만들고 싶은 화면을 말로 설명하면 — 진짜처럼 보이는 프로토타입이 바로 나옵니다.

  • claude.ai/design 에서 바로 시작
  • 디자인 지식·전문 툴 몰라도 됨
  • UI 화면·클릭되는 프로토타입·슬라이드까지

왜 프로토타입에 잘 맞나

손으로 그리거나 코드를 짤 필요 없이 — 몇 초 만에 눈에 보이는 화면이 나옵니다.

  • 머릿속 아이디어를 즉시 화면으로
  • 마음에 안 들면 — 말로 바로 고침
  • 여러 번 다듬어도 부담 없음

Claude Design은 "완성된 디자인"을 뽑는 도구가 아니라 — 아이디어를 빠르게 눈으로 확인하는 도구입니다.

VS · Code & Design

Claude Code와 — 경쟁이 아니라 짝

둘 다 Claude지만 쓰임이 다릅니다. Design으로 화면의 모양을 빠르게 잡고, 진짜 서비스로 키울 땐 Claude Code로 넘깁니다.

Design웹에서 — 화면 모양을 빠르게 시각화
Code내 폴더에 — 진짜 파일·서비스로 제작
흐름모양은 Design → 완성은 Code

HOW · 첫 요청

첫 한 줄 — 무엇을·어떻게·느낌만 담아서

이렇게 설명합니다

  1. 무엇을 — 어떤 화면인지 (앱·페이지 이름)
  2. 어떻게 — 화면에 무엇이 있는지 한두 가지
  3. 느낌 — "밝게", "깔끔하게" 같은 분위기 한마디

막히면 메타프롬프트 — "이런 화면 만들려면 어떻게 설명하면 좋아?"

프롬프트 · 첫 요청 
할 일 목록(투두) 앱 화면 만들어줘.
할 일을 추가하고, 끝나면 체크하는 화면으로.
색은 깔끔하고 밝게.

글로 설명하는 게 기본 — 참고 이미지를 올리거나, 마음에 드는 웹사이트 화면을 그대로 가져올 수도 있습니다.

RESULT · 이렇게 나옵니다

첫 한 줄로 나온 — 진짜 같은 화면

아직 다듬기 전 — 첫 한 줄만으로 나온 화면입니다. 여기서부터 고칠 곳을 말하며 점점 마음에 들게 만듭니다.

프로토타입은 한 번에 끝나지 않습니다 — 2~3바퀴 돌리면서 점점 마음에 들게 만듭니다.

EXAMPLE · 이렇게 다듬습니다

화면을 보다 아쉬운 곳을 그대로 말하기

색

"더 밝고 따뜻하게"

색·분위기를 말로 — 색상 코드 몰라도 됨.

배치

"버튼을 가운데로"

위치·정렬을 일상어로 바꾸기.

글자

"제목을 더 크게"

크기·강조를 보이는 대로 조정.

추가

"로그인 버튼 넣어줘"

필요한 요소를 한마디로 추가.

흐름

"다음 화면도 만들어줘"

화면을 이어 클릭되는 흐름으로.

느낌

"좀 더 고급스럽게"

전체 인상을 분위기 한마디로.

어려운 용어는 필요 없습니다 — 보다가 어색한 곳을 일상어로 말하면 Claude Design이 화면으로 바꿔줍니다.

실습 · 진행

Claude Design 열고 — 화면 한 바퀴

1

claude.ai/design 접속 — 로그인. 안 열리면 TA에게 (유료 플랜에서 이용)

2

소재 하나 골라 첫 한 줄 — 9개 중 하나, "무엇을·어떻게·느낌"

3

미리보기 보고 고칠 점 찾기 — 모르겠으면 "어디를 바꾸면 좋을까?"

4

2~3번 다듬기 — 어색한 곳을 그대로 말해 다시 요청

5

완성하면 — 채팅방에 자랑 — 링크나 내보낸 파일로, 무엇을 다듬었는지 한마디

막히면 Claude Design에게 직접 "이 화면 어떻게 고치지?"라고 물어보세요 — 옆 사람과 "뭐라고 시켰어?"를 나눠보는 것도 좋습니다.

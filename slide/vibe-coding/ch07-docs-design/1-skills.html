INSTALL · 스킬 설치

스킬 설치 — 두 줄이면 끝

마켓플레이스에서 한 번에

공식 문서 스킬은 "마켓플레이스"에서 받습니다. document-skills 묶음 하나에 — PPTX·PDF·DOCX·XLSX가 다 들어 있습니다.

  1. 보관소 등록 — /plugin marketplace add
  2. 설치 — /plugin install document-skills
  3. 적용 — /reload-plugins (또는 claude 재시작)
  4. 메뉴가 뜨면 — 화살표로 골라 "Install" 해도 OK

바꾸기 쉽게

한 번 고치면 전부

테마를 바꾸고 싶으면 DESIGN.md만 — 결과물 전체가 새 테마로 따라옵니다.

DESIGN.md는 본래 웹 화면용 디자인 명세지만 — Claude가 이를 기준으로 PPT·PDF에도 같은 색·글꼴을 입혀, 흩어진 결과물이 "한 브랜드"처럼 보이게 됩니다. 이게 템플릿 통일성입니다.

COMPONENT KIT · 부품 상자

규칙 다음은 — 부품을 미리 만들어 두는 것.

DESIGN.md가 "색·글꼴 규칙"이라면, 컴포넌트 킷은 그 규칙으로 미리 만들어 둔 완성 부품입니다 — 버튼·카드·제목·인용 상자. 한 번 만들어 두면 웹페이지든 PPT든 "이 부품으로"라고만 하면 됩니다.

부품버튼 · 카드 · 제목 · 인용 상자 · 구분선
진열장components.html 한 파일 — 브라우저로 열어 눈으로 확인
재사용새 페이지·PPT 만들 때 @로 참조 — 늘 같은 모양
HANDS-ON · 킷 만들기

내 컴포넌트 킷 — 말 한 번이면 생깁니다

프롬프트 
@DESIGN.md 규칙으로 내 컴포넌트 킷을 만들어줘.
components.html 한 파일에 — 색 팔레트(주색 1 + 보조색 2), 제목·본문 글꼴, 버튼 2종(기본·강조), 카드, 인용 상자, 구분선을 실제 모양으로 보여주고, 부품마다 언제 쓰는지 한 줄씩 적어줘.

완성되면 브라우저로 components.html을 열어 부품들을 구경하세요 — 마음에 안 드는 부품은 "버튼을 더 둥글게" 식으로 그 자리에서 고치면 됩니다.

REUSE · 부품으로 조립

이제 뭘 만들든 — "이 부품으로" 한마디

웹페이지 — 부품 재사용 
@components.html 의 부품과 @DESIGN.md 규칙을 그대로 써서 [스터디 모임 안내] 페이지를 만들어줘. 새 스타일을 만들지 말고 킷에 있는 부품만 조립해줘.
PPT — 같은 테마로 
@DESIGN.md 의 색·글꼴 규칙을 적용해서 자기소개 PPT를 다시 만들어줘. 컴포넌트 킷의 카드 느낌을 슬라이드 레이아웃에도 살려줘.

핵심은 "새로 만들지 말고 킷에서 꺼내 쓰기" — 웹과 PPT가 같은 브랜드로 보이기 시작합니다. 9장 미니프로젝트 발표 PPT에서 이 킷을 그대로 다시 씁니다.

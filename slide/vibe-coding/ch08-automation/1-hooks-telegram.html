Hooks — 자동화의 첫 경험

7장까지 만들었다면 — 이제 Claude가 먼저 말을 걸게 할 차례. "이런 일이 일어나면, 자동으로 이걸 실행" — 이벤트 기반 자동화. 6개 이벤트가 있지만 이번 장에서는 Stop 한 개만.

DEFINITION · Hook이 뭔가

Claude의 사이클 안에 끼어 넣는 자동 실행.

Claude가 일하는 흐름 — 요청을 받고, 실행하고, 응답을 마치는 각 지점에 본인 셸 명령을 끼워 넣을 수 있습니다.

CATALOG · 6 이벤트

Hook 이벤트 — 6가지가 있다 (외울 필요 X)

PreToolUse

도구 사용 전 — 차단·검증.
예) 중요한 파일을 지우기 전 확인

PostToolUse

도구 사용 직후 — 후속 작업.
예) 파일을 수정하면 백업본 저장

Stop ★

응답 끝났을 때 — 이번 장에서 만들 알림.
예) 텔레그램으로 "작업 끝" 알림

UserPromptSubmit

메시지 보낼 때 — 검증·기록.
예) 메시지 보낼 때마다 시각 기록

Notification

Claude가 알림 띄울 때 — 알림 연동.
예) Claude가 물어볼 때 소리로 알림

SubagentStop

서브에이전트(7장에서 배움) 작업 끝.
예) 서브에이전트 끝 → 요약 보여주기

EXAMPLES · 손에 익혀둘 3개

실무에서 가장 자주 보는 Hook 3가지

① Stop · 응답 끝 알림 ★

긴 작업 시키고 다른 일 → 휴대폰 알림 → 복귀.

"Stop": [{ "hooks": [{ "command": "curl ... api.telegram.org/bot.../ sendMessage" }]}]

② PostToolUse · 저장 후 포맷

파일 저장될 때마다 자동 포맷 → 일관성 ↑.

"PostToolUse": [{ "matcher": "Write|Edit", "hooks": [{ "command": "prettier --write $FILE" }]}]

③ PreToolUse · 커밋 전 테스트

git commit 직전 pytest — 깨지면 커밋 차단.

"PreToolUse": [{ "matcher": "Bash", "hooks": [{ "command": "pytest", "blocking": true }]}]

이번 장에서는 ① Stop 알림 한 개만 실습. ②·③은 익숙해진 후 본인 워크플로우에 맞춰 추가.

STEP 3 · chat_id 확보

본인 봇과 첫 대화 → chat_id 받기

단계

  1. 봇 생성 직후 BotFather 메시지에 뜨는 t.me/claude_notify_bot 링크(= 내 봇 주소) 클릭 → 본인 봇 화면 열림
  2. "+ Start" 버튼 → "안녕" 한 번 보내기
  3. 브라우저로 api.telegram.org/bot<TOKEN>/getUpdates
  4. JSON에서 "chat":{"id":...} 숫자 복사
getUpdates JSON
{ "ok": true, "result": [{ "message": { "chat": { "id": 123456789, ... }, "text": "안녕" } }]}# 이 숫자 (123456789) = chat_id

봇과 한 번이라도 대화해야 getUpdates에 chat이 나타납니다 — "안녕" 안 보내면 빈 결과. {"ok":true,"result":[]}처럼 result가 비어 있으면 봇에 채팅을 몇 번 더 보낸 뒤 브라우저에서 F5로 새로고침.

STEP 4 · settings.json 작성

.claude/settings.json — Stop 훅 추가

.claude/settings.json
{ "hooks": { "Stop": [{ "matcher": "", "hooks": [{ "type": "command", "command": "curl -s -X POST https://api.telegram.org/bot<TOKEN>/sendMessage -d chat_id=<CHAT_ID> -d text='Claude Done'" }] }] }}
WINDOWS · 한글 알림이 깨질 때

메시지는 Claude Done처럼 영문으로 시작하면 무탈. Windows 기본 PowerShell(5.1)에서 한글이 깨져 도착하면 — Claude Code에게 "텔레그램 알림 한글이 깨져요, 고쳐줘"라고 하면 PowerShell 방식 또는 인코딩을 자동으로 잡아 줍니다.

<TOKEN>과 <CHAT_ID>를 본인 값으로 교체. 위 command는 화면이 좁아 나눠 보일 뿐 — 실제 파일에선 한 줄로 이어 적습니다(JSON 문자열엔 줄바꿈 불가).

PREP · Channels 사전 준비

Channels 켜기 전 — 두 가지 준비

① Bun 설치 — 플러그인 실행 환경

Bun은 자바스크립트 프로그램을 실행하는 환경입니다 — Node.js의 빠르고 가벼운 대안. 텔레그램 플러그인이 자바스크립트로 만들어져, Bun이 있어야 동작합니다. 아래 명령을 PowerShell터미널에 붙여넣어 설치하세요.

powershell -c "irm bun.sh/install.ps1 | iex"
curl -fsSL https://bun.sh/install | bash

② 조직 관리자 활성화

Channels는 Team/Enterprise 계정에서 기본 차단 — 강의 전, 조직 관리자가 먼저 켜야 합니다.

  • claude.ai → Admin settings → Claude Code → Channels 토글 ON
  • 또는 managed settings에 channelsEnabled: true
  • 안 켜면 --channels blocked by org policy — 메시지가 조용히 버려짐

Bun은 공식 사이트 bun.sh에서 설치 — 끝나면 PowerShell터미널을 새 창으로 다시 엽니다(PATH 반영). 두 준비는 다음 '켜기' 슬라이드 전에 끝나 있어야 합니다.

SETUP · Channels 켜기

플러그인 설치 → --channels로 실행

설치 — 4단계

  1. Claude Code에서 /plugin install telegram@claude-plugins-official 입력 → 끝나면 /reload-plugins
  2. /telegram:configure <토큰> — Stop Hook에 쓴 그 봇 토큰 그대로
  3. /exit 후 claude --channels plugin:telegram@claude-plugins-official로 재시작
  4. 텔레그램에서 봇에게 아무 메시지 → 받은 코드로 /telegram:access pair <코드>

한 번 연결하면 — 텔레그램 봇 채팅창이 곧 Claude 입력창이 됩니다.

알아둘 점

  • 정식 출시 기능 — 안정적으로 사용 가능
  • 정확한 절차는 공식 문서 code.claude.com/docs/en/channels 기준
  • 막히면 강사·TA 호출 — 함께 맞춥니다

설치 단계는 강사가 화면으로 함께 진행합니다 — 한 명씩 따라오면 전원 연결됩니다. 연결 뒤 /telegram:access policy allowlist로 본인만 허용하면 보안이 잠깁니다.

CONCEPT · 한 걸음 더

Claude Code를 넓히는 MCP · Skill · Plugin

MCP

외부 도구 연결

파일·DB·다른 서비스에 Claude가 접근하도록 잇는 통로 — 기능을 바깥으로 확장합니다.

Skill

반복 작업을 /명령어로

자주 하는 작업을 슬래시 명령 하나로 — 긴 지시를 한 줄로. 예: /review.

Plugin

묶어서 설치하는 패키지

MCP·Skill·Hook을 하나로 묶어 /plugin install로 설치 — 가장 큰 단위.

Plugin이 가장 큰 단위 — 그 안에 MCP·Skill이 들어 있습니다. 방금 설치한 telegram도 Plugin — 텔레그램 연결(MCP) + /telegram:configure(Skill)가 한 묶음이었습니다. 다음 덱 — MCP·브라우저 크롤링으로 직접 체험합니다.

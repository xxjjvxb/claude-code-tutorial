글자로 컴퓨터에 말 거는 창

gh1·2장
GitHub를 다루는 명령 도구
저장소 만들기·올리기를 Claude가 대신 실행합니다. 한 번 로그인해두면 그다음부터는 신경 쓸 일이 없습니다.

이 여섯 개가 1장 셋업의 전부입니다. 새 컴퓨터에서 다시 시작해야 한다면 이 순서로 깔면 됩니다.

ZONE ② · .claude/ 폴더

Claude를 내 방식대로 만드는 파일들

CLAUDE.md3장
매번 자동으로 읽히는 규칙집
"한국어로 답해줘", "커밋 메시지는 이렇게" 같은 반복 지시를 적어둡니다. 세션마다 다시 말할 필요가 없어집니다.
커스텀 슬래시3장
자주 하는 부탁을 한 단어로
.claude/commands/에 md 파일 하나 = 명령어 하나. 3장에서 만든 /asdf가 그 예입니다.
Hooks3장
어떤 일이 생기면 자동 실행
settings.json에 적습니다. 응답이 끝나면(Stop) 텔레그램으로 알림 보내기가 대표적. 이벤트 6종이 있습니다.
서브에이전트5장
파일 하나 = 도우미 하나
.claude/agents/에 역할을 적어두면 그 역할로 일합니다. 5장의 designer·developer. 한 번 만들면 계속 재사용.
MCP6장
담장 밖 프로그램으로 뻗는 통로
Claude는 기본적으로 열어둔 폴더 안만 봅니다. MCP를 꽂으면 브라우저·다른 폴더·외부 서비스에 닿습니다.
Skill · Plugin6장
가져다 쓰는 능력 묶음
Plugin이 가장 큰 단위 — 그 안에 MCP와 Skill이 들어 있습니다. 문서 스킬을 설치하면 워드·엑셀·PPT를 만들 수 있게 됩니다.

서브에이전트는 사람, MCP는 도구 — 도우미가 도구를 들고 일하는 그림으로 기억하면 헷갈리지 않습니다.

ZONE ③ · 남의 서버

직접 차리지 않고 — 빌려 쓰는 것들

GitHub2장
코드를 클라우드에 두는 창고
Git은 내 컴퓨터 안, GitHub는 인터넷 위 — 둘은 다릅니다. Private으로 두면 나만 봅니다. 무료.
Vercel2장
서버 운영을 통째로 대신
GitHub 저장소를 한 번 Import하면 이후 push마다 자동 재배포. 개인 프로젝트는 무료(Hobby).
Supabase5장
데이터베이스 + 로그인이 한 묶음
백엔드 서버를 따로 만들지 않고 앱이 바로 데이터에 연결됩니다. 표 만들기는 SQL Editor에서. 무료 티어.
구글 OAuth4장
비밀번호를 내가 안 받는 로그인
Google Cloud Console에서 클라이언트 ID·시크릿을 받고, 배포 주소를 승인된 리디렉트 URI에 넣어야 합니다.
텔레그램 봇3장
알림을 배달해 주는 통로
BotFather에게 /newbot → 토큰. 그 토큰과 chat_id만 있으면 무엇이든 내 폰으로 메시지를 보낼 수 있습니다.
환경변수4·5장
비밀값을 코드 밖에 두는 자리
토큰·키를 코드에 적으면 GitHub에 그대로 올라갑니다. 내 컴퓨터의 .env와 Vercel 대시보드 양쪽에 넣어야 배포본도 동작합니다.

"내 컴퓨터에선 되는데 배포하면 안 돼요"의 절반은 환경변수, 나머지 절반은 승인된 주소 목록입니다.

2부 · KEYWORDS

막히는 건 실력이 아니라 — 이름을 몰라서.

"예약 받는 기능 만들고 싶은데…"에서 멈추는 이유는 그 기능의 이름을 모르기 때문입니다. 이름을 알면 검색이 되고, 검색이 되면 Claude에게 정확히 시킬 수 있습니다. 다음 장부터는 만들고 싶은 것 → 그때 쓰는 이름을 묶어 둡니다.

이름도구·서비스의 실제 이름을 안다
요청"pygame으로 만들어줘"처럼 넣어 말한다
검색모르면 그 이름으로 찾아본다
만들고 싶다 · 게임

게임을 만들고 싶다면 — 이 이름들

pygamePython
파이썬으로 만드는 2D 게임
벽돌깨기·스네이크·간단한 슈팅. 7장에서 배운 파이썬을 그대로 씁니다. 시작하기 가장 쉬운 쪽. 무료.
Phaser웹
브라우저에서 도는 게임
설치 없이 링크만 보내면 친구가 바로 플레이. 2장에서 배운 배포와 그대로 이어집니다. 무료.
Godot엔진
본격적인 무료 게임 엔진
2D·3D 다 됩니다. 화면을 보며 배치하는 방식이라 코드만으로 만드는 것보다 감이 빨리 옵니다.
게임 루프
입력 → 계산 → 그리기의 반복
모든 게임의 심장. "1초에 60번 이걸 반복한다"는 구조를 알면 어떤 엔진이든 이해가 빨라집니다.
스프라이트
움직이는 그림 조각
캐릭터·아이템 이미지를 부르는 말. "스프라이트 시트"는 여러 동작을 한 장에 모아둔 이미지입니다.
충돌 판정
부딪혔는지 알아내는 계산
영어로 collision detection. "총알이 적에게 맞았는지"를 판단하는 부분 — 게임에서 가장 자주 손보는 곳.

처음이면 pygame 또는 Phaser. "파이썬 pygame으로 벽돌깨기 만들어줘"처럼 이름을 넣어 말하면 시작이 빠릅니다.

만들고 싶다 · 자동화

반복 작업을 대신 시키고 싶다면

Playwright7장
브라우저를 대신 조작
로그인하고, 클릭하고, 값을 읽어 옵니다. 웹에서 하는 반복 작업은 대부분 이걸로 됩니다. 이미 써 봤습니다.
Selenium
Playwright의 원조 격
더 오래됐고 자료가 많습니다. 검색하면 예제가 압도적으로 많아서 참고용으로 알아둘 만합니다.
pyautogui
화면·키보드·마우스를 직접
브라우저가 아니라 화면 전체를 다룹니다. 웹이 아닌 프로그램(엑셀 창 등)을 자동화할 때.
스케줄러 · cron부록 A
정해둔 시각에 자동 실행
윈도우는 작업 스케줄러, 맥·리눅스는 cron·launchd. "매일 아침 9시에"를 담당합니다.
웹훅 (webhook)
일이 생기면 알려 달라고 등록
계속 물어보는(폴링) 대신, 저쪽에서 먼저 알려 주게 하는 방식. 결제 완료·새 글 알림이 이걸로 옵니다.
RPA
사무 자동화를 부르는 업계 용어
검색할 때 유용한 단어. 회사에서 "이거 RPA로 되나요"라고 물으면 대개 위의 도구들 이야기입니다.

순서가 있습니다 — 웹이면 Playwright, 웹이 아니면 pyautogui, 시간표가 필요하면 스케줄러.

만들고 싶다 · 일정·협업

예약 받고, 다른 서비스와 잇고 싶다면

Google Calendar API
구글 캘린더에 일정 넣고 읽기
예약 페이지를 만들면 대개 여기로 연결합니다. 로그인 방식은 4장에서 한 구글 OAuth와 같습니다. 무료.
범위 (scope)
"어디까지 허락받을지"
읽기만인지 쓰기까지인지를 정하는 값. 구글 연동에서 가장 자주 막히는 지점이라 이 단어를 알아두면 좋습니다.
iCalendar (.ics)
일정 파일의 공통 형식
"내 캘린더에 추가" 버튼이 내려주는 그 파일. 특정 회사에 묶이지 않고 어디서나 열립니다.
Notion API
노션 페이지·표를 읽고 쓰기
노션을 데이터베이스처럼 씁니다. 팀이 이미 노션을 쓴다면 새 화면을 만들 것 없이 여기에 쌓는 게 빠릅니다.
Slack API
슬랙으로 알림·명령
3장의 텔레그램과 역할이 같습니다. 회사에서 쓰면 이쪽. Incoming Webhook 한 줄이면 메시지가 갑니다.
Zapier · Make
코드 없이 서비스끼리 연결
"폼이 제출되면 → 시트에 적고 → 슬랙 알림"을 화면에서 조립. 직접 만들기 전에 이걸로 될지 먼저 확인해 보세요.

남의 서비스에 연결할 때 열쇠말은 늘 같습니다 — API · 인증(OAuth) · 범위(scope) · 웹훅.

지오코딩
주소 ↔ 위경도 변환
"서울시 중구 …"를 지도에 찍으려면 숫자 좌표로 바꿔야 합니다. 그 변환의 이름. 반대는 역지오코딩.
마커 · 폴리라인
핀 찍기 · 선 그리기
마커는 지도 위의 핀, 폴리라인은 경로 선. "마커 클러스터링"은 핀이 많을 때 묶어 보여 주는 기능입니다.
위경도 (lat/lng)
지도의 좌표 단위
위도(lat)·경도(lng) 두 숫자. 데이터를 Supabase에 저장할 때도 이 두 칸으로 넣습니다.

국내 서비스면 네이버 또는 카카오부터. "카카오맵 API로 이 주소들을 지도에 마커로 찍어줘"처럼 말하면 됩니다.

만들고 싶다 · 결제·알림

돈을 받고, 소식을 보내고 싶다면

토스페이먼츠국내
카드 결제 붙이기
국내 결제 연동 중 문서가 친절한 편. 테스트 키로 실제 돈 없이 먼저 만들어 볼 수 있습니다.
포트원 (아임포트)국내
여러 결제사를 한 번에
카드·계좌·간편결제를 한 연동으로 묶어 줍니다. 결제 수단을 여러 개 두고 싶을 때.
Stripe해외
해외 결제·구독의 표준
해외 대상 서비스라면 사실상 기본값. 구독(정기결제) 기능이 특히 잘 만들어져 있습니다.
결제 웹훅
"진짜 결제됐다"를 확인하는 길
화면에서 성공했다고 끝내면 안 됩니다. 결제사가 서버로 보내 주는 신호를 받아 확정해야 안전합니다.
FCM 푸시
앱·브라우저로 가는 푸시 알림
텔레그램 봇보다 정식이지만 손이 더 갑니다. 개인 프로젝트면 텔레그램이 훨씬 빠릅니다.
Resend · SendGrid
이메일 보내기
가입 확인 메일·알림 메일. 내 지메일로 직접 보내면 스팸으로 걸리기 쉬워서 이런 서비스를 씁니다.

결제는 테스트 키로 먼저 끝까지 만들어 보세요. 실제 카드는 흐름이 다 돌아간 뒤에 붙이면 됩니다.

만들고 싶다 · 데이터·AI

데이터를 다루고 AI를 얹고 싶다면

pandas부록 B
표 데이터를 다루는 기본 도구
엑셀로 하던 일을 코드로. 수십만 줄도 한 번에 거르고 합칩니다. 파이썬 데이터 작업의 출발점.
Anthropic · OpenAI API
내가 만든 앱 안에 AI 넣기
Claude Code로 만드는 것과 다릅니다 — 내 프로그램이 AI를 호출하는 것. 쓴 만큼 요금이 나갑니다.
RAG
내 문서를 읽고 답하는 챗봇
"우리 회사 규정 알려주는 챗봇"이 이것. 문서를 잘게 잘라 저장해두고 질문과 비슷한 조각을 찾아 답합니다.
임베딩 · 벡터 DB
뜻이 비슷한 걸 찾아내는 방식
글을 숫자 뭉치로 바꿔 "비슷함"을 계산합니다. RAG의 속재료. Supabase에도 이 기능이 있습니다.
OCR
이미지 속 글자를 텍스트로
영수증·스캔 문서를 읽어 표로 만들 때. 요즘은 AI 모델에 이미지를 그대로 주는 방법도 잘 됩니다.
Whisper
음성을 텍스트로
회의 녹음·영상 자막. 받아쓴 뒤 AI에게 요약을 시키는 조합이 특히 자주 쓰입니다.

헷갈리기 쉬운 지점 — Claude Code는 내가 쓰는 도구, API는 내 프로그램이 쓰는 도구입니다.

만들고 싶다 · 앱·문서

앱으로, 문서로 — 형태를 바꾸고 싶다면

Flutter · React Native
폰에 설치되는 앱
한 번 만들어 iOS·안드로이드 양쪽으로. 다만 스토어 심사가 필요하니, 급하면 웹으로 먼저 만드는 게 빠릅니다.
PWA
웹인데 앱처럼 설치되는 것
홈 화면에 아이콘이 생기고 전체화면으로 뜹니다. 스토어 없이 앱 느낌을 낼 때 가장 저렴한 길.
PySide6 · Electron7장
PC에서 도는 프로그램
PySide6는 파이썬으로(7장에서 사용), Electron은 웹 기술로 데스크톱 앱을 만듭니다.
python-docx · openpyxl
코드로 워드·엑셀 만들기
6장 문서 스킬이 안쪽에서 쓰는 것들. 정해진 양식을 매달 자동으로 채워야 할 때 직접 쓰게 됩니다.
Pillow
이미지 자르기·크기 조정·합성
썸네일 만들기, 워터마크 넣기, 여러 장 한 번에 줄이기. 파이썬 이미지 작업의 기본.
QR · 바코드
qrcode · pyzbar
만들기는 qrcode, 읽기는 pyzbar. 출석 체크·입장 확인 같은 걸 만들 때 자주 등장합니다.

형태를 고르는 기준 하나 — 링크로 보낼 수 있으면 웹, 내 컴퓨터에서만 쓸 거면 실행 파일.

WRAP · 이 단어를 쓰는 법

이름을 알았으니 — 이렇게 말합니다

1

이름을 넣어 말한다

"지도 넣어줘"보다 "카카오맵 API로 이 주소들을 마커로 찍어줘". 도구가 정해지면 결과가 흔들리지 않습니다.

2

모르면 먼저 물어본다

"예약 기능을 만들려면 보통 뭘 쓰나요? 선택지와 장단점을 알려주세요" — 만들기 전에 이름부터 받아냅니다.

3

작게 먼저 붙인다

결제도 지도도 테스트 키·샘플 데이터로 끝까지 한 바퀴 돌린 뒤 실제 값으로 바꿉니다. 3장에서 배운 순서 그대로.

여기 없는 것도 방법은 같습니다 — 만들고 싶은 것을 한 문장으로 적고, 그 분야의 이름을 먼저 물어보세요.

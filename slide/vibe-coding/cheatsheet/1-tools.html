① 내 컴퓨터
Orca + Claude Code
작업실과 일하는 사람
Orca는 편집기와 터미널이 한 화면인 작업실, Claude Code는 그 안에서 내 파일을 읽고 고치는 에이전트. 1장
.claude/ 설정
Claude를 길들이는 파일들
CLAUDE.md(규칙) · commands(내 명령어) · agents(도우미) · settings.json(훅). 3·5장
Git+ gh
되돌리기 · 올리기
Git은 내 컴퓨터 안의 시간여행 장치, gh는 GitHub에 올리는 명령 도구. 1·2장
Python · Node.js
프로그램이 도는 바닥
Python은 3장 미션과 7장 실행파일의 바닥, Node.js는 미리보기 서버와 MCP가 올라타는 바닥. 3·4장
→git push
② 빌려 쓰는 클라우드
GitHub
코드가 사는 창고
내 컴퓨터의 커밋을 push하면 여기 쌓입니다. Vercel이 여기서 코드를 가져갑니다. 2장
Vercel
주소를 만들어 주는 곳
GitHub와 한 번 연결해두면 push할 때마다 자동 재배포. 토큰 같은 환경변수도 여기에 넣습니다. 2장
Supabase
데이터가 남는 곳
표에 글이 쌓이고, 누가 쓸 수 있는지 규칙도 여기서 막습니다. 로그인 연결도 담당. 5장
구글 로그인
누구인지 확인해 주는 곳
비밀번호는 구글이 확인하고, 내 서비스는 확인됨만 받습니다. 4장
텔레그램 봇
알림이 지나가는 곳
보내는 쪽이 둘입니다 — 내 컴퓨터의 훅(3장), 그리고 배포된 사이트(5장). 받는 채팅방은 같습니다.

.exe / .app
투두·트레이더·코인차트 — 파이썬 없는 PC에서도 더블클릭으로 도는 프로그램. 7장
문서 · PPT

④ 바깥세상 데이터
공개 API가 있다
주소로 요청 → JSON으로 받기
날씨·업비트 시세·강의 가상 시장처럼 데이터를 정식으로 내주는 곳. 먼저 이걸 찾습니다. 4·7장
API가 없다
Playwright로 사람처럼 긁기
쇼핑몰처럼 API를 안 주는 곳은 브라우저를 열어 보고 읽습니다. 이용 규칙은 지키면서. 7장

그리고 나 — 계획을 검토하고, 권한을 승인하고, 결과를 확인합니다. 이 자리만은 위임하지 않습니다.

ZONE ① · 내 컴퓨터

내 작업대에 설치한 것들

Orca1장
편집기 + 터미널이 한 화면인 작업실
AI 에이전트용 작업 환경. 폴더를 홈베이스로 등록해두고 거기서 Claude를 띄웁니다. 좌하단에 사용량이 늘 보입니다. 무료.
Claude Code1장
터미널에 사는 코딩 에이전트
내 폴더의 파일을 직접 읽고·쓰고·실행합니다. 채팅창에 코드를 복사해 오는 방식과 다른 지점이 바로 이것.
터미널1장
글자로 컴퓨터에 말 거는 창
윈도우는 PowerShell, 맥은 zsh. Orca 안에 내장돼 있습니다. 읽기용 명령 몇 개만 알면 충분합니다.
Git1·2장
코드의 시간여행 장치
AI가 파일을 고치는 시대의 안전벨트. 커밋해두면 언제든 그 시점으로 되돌아갑니다. 자주 커밋할수록 안전.
gh1·2장
GitHub를 다루는 명령 도구
저장소 만들기·올리기를 Claude가 대신 실행합니다. 한 번 로그인해두면 그다음부터는 신경 쓸 일이 없습니다.
Python · Node.js3·4장
프로그램이 올라타는 바닥
Python은 3장 미니미션과 7장 실행파일의 바닥, Node.js는 로컬 미리보기 서버와 6장 MCP가 도는 바닥입니다.

이 여섯 개가 1장 셋업의 전부입니다. 새 컴퓨터에서 다시 시작해야 한다면 이 순서로 깔면 됩니다.

ZONE ② · .claude/ 폴더

Claude를 내 방식대로 만드는 파일들

CLAUDE.md3장
매번 자동으로 읽히는 규칙집
"한국어로 답해줘", "커밋 메시지는 이렇게" 같은 반복 지시를 적어둡니다. 세션마다 다시 말할 필요가 없어집니다.
커스텀 슬래시3장
자주 하는 부탁을 한 단어로
.claude/commands/에 md 파일 하나 = 명령어 하나. 3장에서 만든 /asdf가 그 예입니다.
Hooks3장
어떤 일이 생기면 자동 실행
settings.json에 적습니다. 응답이 끝나면(Stop) 텔레그램으로 알림 보내기가 대표적. 이벤트 6종이 있습니다.
서브에이전트5장
파일 하나 = 도우미 하나
.claude/agents/에 역할을 적어두면 그 역할로 일합니다. 5장의 designer·developer. 한 번 만들면 계속 재사용.
MCP6장
담장 밖 프로그램으로 뻗는 통로
Claude는 기본적으로 열어둔 폴더 안만 봅니다. MCP를 꽂으면 브라우저·다른 폴더·외부 서비스에 닿습니다.
Skill · Plugin6장
가져다 쓰는 능력 묶음
Plugin이 가장 큰 단위 — 그 안에 MCP와 Skill이 들어 있습니다. 문서 스킬을 설치하면 워드·엑셀·PPT를 만들 수 있게 됩니다.

서브에이전트는 사람, MCP는 도구 — 도우미가 도구를 들고 일하는 그림으로 기억하면 헷갈리지 않습니다.

ZONE ③ · 남의 서버

직접 차리지 않고 — 빌려 쓰는 것들

GitHub2장
코드를 클라우드에 두는 창고
Git은 내 컴퓨터 안, GitHub는 인터넷 위 — 둘은 다릅니다. Private으로 두면 나만 봅니다. 무료.
Vercel2장
서버 운영을 통째로 대신
GitHub 저장소를 한 번 Import하면 이후 push마다 자동 재배포. 개인 프로젝트는 무료(Hobby).
Supabase5장
데이터베이스 + 로그인이 한 묶음
백엔드 서버를 따로 만들지 않고 앱이 바로 데이터에 연결됩니다. 표 만들기는 SQL Editor에서. 무료 티어.
구글 OAuth4장
비밀번호를 내가 안 받는 로그인
Google Cloud Console에서 클라이언트 ID·시크릿을 받고, 배포 주소를 승인된 리디렉트 URI에 넣어야 합니다.
텔레그램 봇3장
알림을 배달해 주는 통로
BotFather에게 /newbot → 토큰. 그 토큰과 chat_id만 있으면 무엇이든 내 폰으로 메시지를 보낼 수 있습니다.
환경변수4·5장
비밀값을 코드 밖에 두는 자리
토큰·키를 코드에 적으면 GitHub에 그대로 올라갑니다. 내 컴퓨터의 .env와 Vercel 대시보드 양쪽에 넣어야 배포본도 동작합니다.

"내 컴퓨터에선 되는데 배포하면 안 돼요"의 절반은 환경변수, 나머지 절반은 승인된 주소 목록입니다.

ZONE ④ · 바깥세상

데이터를 얻는 두 갈래

① API가 있다 — 먼저 이걸 찾는다
주소로 요청하면 JSON으로 준다
빠르고, 안 깨지고, 규칙이 명확
날씨 · 업비트 시세 · 공공데이터
가입·키가 필요한 곳도 있다

4장 웹페이지 · 7장 내 프로그램이 이걸 씀.

② API가 없다 — 그때 크롤링
Playwright로 브라우저를 연다
사람처럼 보고 읽어서 가져온다
쇼핑몰 등 대부분의 사이트
화면이 바뀌면 같이 고쳐야 한다

7장 덱 4에서 실제로 해 봤습니다.

순서가 중요합니다 — API를 먼저 찾고, 없을 때 브라우저로. 그리고 어느 쪽이든 그 사이트의 이용 규칙은 지킵니다.

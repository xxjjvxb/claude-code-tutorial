TERMINAL · 짧은 역사

터미널은 컴퓨터의 가장 오래된 입구입니다

1970s
Unix · 초기 컴퓨터는 화면이 없었다. 키보드와 텍스트만 있는 단말기(terminal)로 명령.
1980s
Apple/Windows GUI 등장 — 마우스로 클릭하는 시대 시작. 그러나 터미널은 사라지지 않음.
현재
개발자 · 시스템 운영자는 여전히 터미널 사용. 자동화 · 정확성 · 속도가 GUI보다 우월하기 때문.

터미널이 다시 주목받는 이유: AI에게 텍스트로 시키는 게 가장 자연스럽기 때문. 50년 된 인터페이스가 AI 시대에 가장 적합한 입구가 됐습니다.

FILE PATH · 절대 vs 상대

파일 위치를 표현하는 두 가지 방법

절대 경로 (Absolute)

최상위부터 적는 길 — 어디서든 같은 위치.

  • C:\Users\you\Desktop\my-intro\app.html/Users/you/Desktop/my-intro/app.html
  • 드라이브 문자(C:)부터 시작루트(/)부터 시작 · 길지만 명확

상대 경로 (Relative)

현재 위치 기준으로 짧게.

  • app.html — 같은 폴더
  • ./logs/ 하위 · ../ 부모
C:\Users\you\Desktop\ └── my-intro\ ← 현재 위치 (pwd) ├── app.html ← 상대: "app.html" └── style.css ← 절대: "C:\...\my-intro\style.css"
/Users/you/Desktop/ └── my-intro/ ← 현재 위치 (pwd) ├── app.html ← 상대: "app.html" └── style.css ← 절대: "/Users/.../my-intro/style.css"

한글 Windows에서 \와 ₩는 같은 문자. PowerShell은 /도 동일 인식 → cd C:/Users/you/my-intro OK.

Mac은 / 슬래시만 쓰고, 홈 폴더 줄임 ~ 이 자주 등장 — ~/Desktop/my-intro = /Users/you/Desktop/my-intro. 한글 macOS의 Finder는 "데스크탑"으로 보여도 실제 경로는 영문 Desktop.

RESPONSE PATTERNS · 응답이 오는 방식

응답은 3가지 형태로 옵니다

① 즉답 (짧음)

단순 질문 — 1~2초 안에 답변.

> pwd가 뭐야? Print Working Directory의 약자로...

② 진행 표시 (긴 작업)

파일 만들고 실행할 때 — 단계별 표시.

계획 수립 중... ✓ app.html 생성 ✓ style.css 생성 ✓ 검증 완료

③ 권한 요청 (멈춤)

위험 작업 전 — 사용자 승인 대기.

⚠ Claude wants to run: npm install express [Allow / Deny]

응답이 길어지면 Ctrl+C로 중단. 마음에 안 들면 다시 더 명확하게 시키면 됩니다.

TOKENS · 첫 비용 감각

토큰이 곧 비용입니다

1 token
대략 한국어 1자 또는 영어 4자

"안녕" = 약 2-3 토큰. 코드 한 줄 = 10-30 토큰. 파일 하나 = 수백~수천.

하루 $1~5
일반 사용 비용 범위

Sonnet 기준 — 입력 $3/1M, 출력 $15/1M 토큰. 코드 작업 많은 날은 $10+ 까지. /clear로 자주 끊어 쓰면 절약.

/usage
현재 사용량 확인

실습 중 자주 쳐서 본인 페이스 확인. 결과물 공유 때 단톡방에 공유.

컨텍스트(이전 대화 + 파일)가 길어질수록 매 요청마다 토큰이 비례해서 늘어납니다. 긴 세션 = 큰 비용. 끊어 쓰는 게 절약.

이어지는 두 슬라이드에서 가장 많이 쓰는 4개를 더 자세히 봅니다.

SLASH DEEP · /help · /clear

막혔을 때 / 새로 시작하고 싶을 때

/help — 명령어 모음

현재 세션의 모든 슬래시 · 단축키를 보여준다.

  • 버전 올라가면 새 명령 추가 — 가끔 확인
  • 특정 명령 도움말: /help /usage

/clear — 컨텍스트 초기화

현재 대화를 모두 지우고 새 세션처럼 시작.

  • 이전 대화 빠짐 → 다음 요청부터 토큰 ↓
  • 대화가 엉켰을 때 가장 빠른 회복
  • CLAUDE.md는 /clear 후에도 자동 주입 유지
SLASH DEEP · /usage · /resume

비용 추적 / 끊어진 작업 이어가기

/usage — 사용량

세션의 토큰 · 비용 누적치를 보여준다.

  • 입력/출력 토큰 분리 + 달러 환산
  • 현재 모델 표시
  • 실습 중 의무 체크 (우리의 약속 04)

/resume — 이전 세션 복귀

세션 종료 후 다시 켰을 때 이전 대화 이어가기.

  • 같은 폴더에서 claude 재실행 → /resume
  • 네트워크·노트북 잠김으로 끊겼을 때 유용
  • 여러 세션 중 선택 가능

/clear와 /resume은 반대 방향의 도구. /clear = 깨끗이 시작, /resume = 이어 가기.

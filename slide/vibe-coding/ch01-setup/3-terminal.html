TERMINAL · 짧은 역사

터미널은 컴퓨터의 가장 오래된 입구입니다

1970s
Unix · 초기 컴퓨터는 화면이 없었다. 키보드와 텍스트만 있는 단말기(terminal)로 명령.
1980s
Apple/Windows GUI 등장 — 마우스로 클릭하는 시대 시작. 그러나 터미널은 사라지지 않음.
현재
개발자 · 시스템 운영자는 여전히 터미널 사용. 자동화 · 정확성 · 속도가 GUI보다 우월하기 때문.

터미널이 다시 주목받는 이유: AI에게 텍스트로 시키는 게 가장 자연스럽기 때문. 50년 된 인터페이스가 AI 시대에 가장 적합한 입구가 됐습니다.

  • AI와 찰떡

PROMPT · 줄 앞의 기호

줄 앞의 PS>$ 는 OS 표시 — 명령어 X

⚠️ 따라 치지 말 것

강의 예시에 PS> pwd$ pwd 처럼 적혀 있다면 — 앞의 PS>$는 "여기부터 명령어다"를 알려 주는 OS 신호일 뿐. 실제로 치는 건 pwd 한 단어만.

💡 우상단 OS 토글

화면 우상단 Win ⇄ Mac 토글을 누르면 — 이 강의 전체의 프롬프트와 명령어가 본인 OS에 맞게 바뀝니다. 한 번만 누르면 다음 슬라이드부터 끝까지 유지.

앞으로 등장하는 모든 PS>$는 같은 의미 — 여기부터 사용자가 친 명령. Claude가 명령 실행 승인을 물을 때도 같은 형태로 보입니다.

FILE PATH · 절대 vs 상대

파일 위치를 표현하는 두 가지 방법

절대 경로 (Absolute)

최상위부터 적는 길 — 어디서든 같은 위치.

  • C:\lecture\my-intro\app.html/Users/you/lecture/my-intro/app.html
  • 드라이브 문자(C:)부터 시작루트(/)부터 시작 · 길지만 명확

상대 경로 (Relative)

현재 위치 기준으로 짧게.

  • app.html — 같은 폴더
  • ./logs/ 하위 · ../ 부모
C:\lecture\ └── my-intro\ ← 현재 위치 (pwd) ├── app.html ← 상대: "app.html" └── style.css ← 절대: "C:\...\my-intro\style.css"
/Users/you/lecture/ └── my-intro/ ← 현재 위치 (pwd) ├── app.html ← 상대: "app.html" └── style.css ← 절대: "/Users/.../my-intro/style.css"

한글 Windows에서 \와 ₩는 같은 문자. PowerShell은 /도 동일 인식 → cd C:/Users/you/my-intro OK.

Mac은 / 슬래시만 쓰고, 홈 폴더 줄임 ~ 이 자주 등장 — ~/lecture/my-intro = /Users/you/lecture/my-intro.

CLAUDE CODE INTERFACE · TUI 화면

claude 실행하면 이런 화면이 나옵니다

화면 구성 요소

  • 상단 헤더 — 현재 모델 · 폴더
  • 대화 영역 — 본인 입력 + Claude 응답
  • 입력란 — > 표시 옆에 타이핑
  • 하단 상태 — 토큰 사용량 · 모드 표시

마우스 사용 안 함 — 키보드만. Enter로 전송, Esc(또는 Ctrl+C)로 응답 중단.

RESPONSE PATTERNS · 응답이 오는 방식

응답은 3가지 형태로 옵니다

① 즉답 (짧음)

단순 질문 — 1~2초 안에 답변.

> pwd가 뭐야? Print Working Directory의 약자로...

② 진행 표시 (긴 작업)

파일 만들고 실행할 때 — 단계별 표시.

계획 수립 중... ✓ app.html 생성 ✓ style.css 생성 ✓ 검증 완료

③ 권한 요청 (멈춤)

위험 작업 전 — 사용자 승인 대기.

⚠ Claude wants to run: npm install express [Allow / Deny]

응답이 길어지면 Esc(또는 Ctrl+C)로 중단. 마음에 안 들면 다시 더 명확하게 시키면 됩니다.

SLASH COMMANDS · 카탈로그

자주 쓰는 슬래시 6가지

/help
사용 가능한 명령어 모음 — 막히면 가장 먼저
/clear
컨텍스트 초기화 — 비용 · 집중력 절약
/model
모델 변경 (Haiku · Sonnet · Opus — 플랜에 따라 Fable 5도 표시)
/resume
이전 세션 이어가기 — 작업 끊겼을 때
/login
계정 다시 로그인 — 인증 에러 때
/exit
claude 종료 — 터미널로 복귀

사용량은 Orca 좌하단에 상시 표시 — 명령 없이 흘끗 확인하는 습관 (/usage 명령도 있지만 쓸 일이 없습니다). /clear 후에도 CLAUDE.md는 자동 유지 — 자세한 사용 구분은 3장에서 다룹니다.

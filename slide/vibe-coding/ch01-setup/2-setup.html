STEP 02 · CONCEPT · 환경변수 · PATH

환경변수 — 시스템이 공유하는 설정값

PATH가 뭔가

"명령어를 어디서 찾을지" 폴더 목록을 적어둔 환경변수.

  • PowerShell셸(zsh)이 claude를 PATH 폴더들에서 검색
  • 설치 스크립트가 PATH에 자동 추가
  • 새로 등록된 PATH는 새 PowerShell터미널 창에서만 적용
PATH (시스템 환경변수) ├── C:\Windows\System32 ├── C:\Users\you\.claude\bin\ ← claude.cmd └── ... PS> claude → 위 폴더들에서 검색 → 실행
$PATH (환경변수) ├── /usr/local/bin ├── /usr/bin ├── ~/.claude/bin/ ← claude └── ... $ claude → 위 폴더들에서 검색 → 실행

"인식되지 않습니다command not found"는 99% PATH 문제. 새 PowerShell터미널 창이 1차 해결책.

STEP 03 · Git + GitHub CLI 설치

먼저 — git + gh 설치하고 신원 등록

git-scm.com에서 받기

git-scm.com/download/win ↗

노란색 "Git for Windows/x64 Setup" 클릭 → 받은 파일 실행 → 옵션은 전부 기본값으로 Install. 이어서 GitHub CLI(gh)도 — 새 PowerShell에서 한 줄:

PS> winget install --id GitHub.cli -e

winget이 없다는 메시지가 뜨면 — cli.github.com에서 설치 파일을 받아 실행합니다.

Mac은 이미 깔려 있을 가능성 높음

터미널에서 git --version을 먼저 쳐 보세요.

  • 버전이 나오면 설치 끝 — 신원 등록만 하면 됨
  • "command not found"가 뜨면 Xcode Command Line Tools가 떠요 → xcode-select --install 후 동의 + 설치 (5~10분)
  • 또는 Homebrew 사용자는 brew install git 한 줄
  • GitHub CLI(gh)는 brew install gh — Homebrew가 없으면 cli.github.com에서 다운로드
PowerShellTerminal (zsh) — 새 창에서
# 설치가 됐는지 — 버전 확인 (둘 다) git --version git version 2.x.x gh --version gh version 2.x.x# 커밋에 남길 신원 — 최초 1회만 git config --global user.name "홍길동" git config --global user.email "hong@example.com"

왜 Claude보다 먼저? claude가 작업 도중 git과 gh(GitHub 명령 도구)를 자동으로 호출합니다 — 없으면 흐름이 끊겨요. git config 두 줄은 평생 한 번만. gh 로그인은 지금 안 해도 됩니다 — 2장에서 GitHub 계정을 만들 때 함께 합니다.

STEP 04 · Claude Code 설치

설치 방법 3가지 — 본인 환경에 맞게

방법 1 · PowerShell 한 줄 — 이번 강의 메인
PowerShell · 붙여넣기 
irm https://claude.ai/install.ps1 | iex
irm 다운로드 · iex 실행 — Node.js 없이 한 줄.
방법 2 · cmd 한 줄
> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
PowerShell 정책이 막혀 있을 때 대안.
방법 3 · npm 전역 (Node.js 이미 있을 때)
PS> npm install -g @anthropic-ai/claude-code
npm update로 업데이트도 한 줄.
방법 1 · 터미널 한 줄 — 이번 강의 메인
터미널 · 붙여넣기 
curl -fsSL https://claude.ai/install.sh | bash
다운로드 후 즉시 실행 — Node.js 없이 한 줄.
방법 2 · Homebrew (이미 brew 쓰는 분)
$ brew install anthropic/tap/claude-code
설치·업데이트를 brew upgrade 한 줄로.
방법 3 · npm 전역 (Node.js 이미 있을 때)
$ npm install -g @anthropic-ai/claude-code
npm update로 업데이트도 한 줄.

설치 직후 PowerShell터미널을 껐다 새로 열어야 PATH 갱신 → claude 인식. 실패 시 → 관리자 권한 PowerShell.실패 시 → sudo 또는 권한 확인.

STEP 07 · 첫 실행

claude로 "안녕하세요"

쉬운 방법 · 마우스 우클릭

  1. 바탕화면 빈 공간 우클릭 → 새로 만들기 → 폴더
  2. 폴더 이름 my-intro 입력
  3. my-intro 폴더 안 빈 공간 우클릭 → "터미널에서 열기"
  4. 열린 PowerShell에 claude 입력
  5. 처음이면 브라우저 로그인 창 → 교육 팀 계정 메일로 로그인

쉬운 방법 · Finder에서

  1. Finder → 데스크탑에서 빈 공간 우클릭 → 새로운 폴더
  2. 폴더 이름 my-intro 입력
  3. my-intro 폴더를 우클릭 → "폴더에 있는 새로운 터미널" (서비스 메뉴)
  4. 열린 터미널에 claude 입력
  5. 처음이면 브라우저 로그인 창 → 교육 팀 계정 메일로 로그인
claude — my-intro/

Windows 10이라면 Shift + 우클릭 → "여기에서 PowerShell 창 열기". 또는 cd C:\Users\본인계정\Desktop\my-intro.

우클릭 메뉴에 "폴더에 있는 새로운 터미널"이 없으면 시스템 환경설정 → 키보드 → 단축키 → 서비스에서 활성화. 또는 cd ~/Desktop/my-intro.

STEP 07 (첫 로그인) · 브라우저 인증

브라우저가 안 열리면 터미널에 표시되는 URL을 직접 복사해 붙여넣으세요. 로그인은 최초 1회만 — 이후엔 claude 입력만으로 바로 시작됩니다.

필수 · Node.js · 홈페이지 배포 준비

Node.js — 지금 설치해 둡니다

받는 곳
https://nodejs.org
  1. nodejs.org 접속 → "LTS" 큰 버튼 클릭 (Windows .msi 자동 다운로드)
  2. node-v22.x.x-x64.msi(LTS 버전 숫자는 다를 수 있음) 더블클릭 → 보안 경고 "예" → 설치 마법사 Next 따라 진행
  3. Custom Setup에서 "Add to PATH" 체크 확인 → Install → UAC 승인 → 1~2분 대기
  4. 완료 후 새 PowerShell에서 node --version → v22.x.x 처럼 버전 숫자가 나오면 OK
받는 곳
Homebrew · nodejs.org
  1. Homebrew가 설치돼 있으면 brew install node 한 줄 — 30초~1분
  2. Brew가 없으면 nodejs.org → "LTS" 버튼 → .pkg 다운로드 → 더블클릭 → 설치 마법사
  3. 설치 후 새 터미널에서 node --version → v22.x.x 처럼 버전 숫자가 나오면 OK
  4. Homebrew 자체 설치는 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

왜 필요? 홈페이지를 만들고 배포할 때 쓰는 웹 도구들(로컬 미리보기 서버·배포 도구)이 Node.js 위에서 돌아갑니다 — 2장 배포까지 가려면 필수.

선택 · TROUBLESHOOTING · 자주 막히는 5가지

막혔을 때 먼저 시도할 것들

01
"인식되지 않습니다command not found"
새 PowerShell터미널 창 → PATH 갱신. 안 되면 시작 메뉴Spotlight에서 다시 검색해 실행.
02
PowerShell 스크립트 실행 정책 에러
관리자 PowerShell → Set-ExecutionPolicy -Scope CurrentUser RemoteSigned → 재시도.
02
"Permission denied" / 실행 권한 에러
설치 스크립트를 다시 실행하거나, 막힌 파일에 chmod +x ~/.claude/bin/claude. Mac은 별도 정책 없음 — 권한만 맞으면 OK.
03
claude 실행 시 결제·인증 에러
팀 초대 메일을 받아 수락했는지 확인. 안 왔으면 강사에게 메일 주소 등록 요청.
04
로그인 브라우저가 안 열림
터미널에 표시되는 URL을 직접 복사해서 브라우저에 붙여넣기.
05
Orca가 안 열리거나 이상하게 동작
완전히 종료 후 다시 실행 → 그래도 안 되면 onorca.dev에서 최신 버전 재설치.

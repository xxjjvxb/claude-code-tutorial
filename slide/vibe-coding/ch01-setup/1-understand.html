DEFINITION · 정의 한 줄

터미널에 사는
AI 코딩 에이전트다.

브라우저 채팅창이 아니라, 내 컴퓨터 안에서 직접 돈다. 지시만 내리면 스스로 판단해서 처리한다.

01파일을 직접 읽고 · 쓰고 · 실행한다
02위험한 일은 매번 물어본다 (안전장치)
03프로젝트 맥락(@멘션 · CLAUDE.md)을 이해한다
DIFFERENTIATORS · 개요

ChatGPT와 무엇이 다른가

01

내 컴퓨터 안에서 산다

내 폴더에서 직접 파일을 읽고·쓰고·실행. 복붙 노가다 0회.

02

직접 행동한다
대신 물어본다

위험한 일(삭제·외부 호출)은 매번 물어본다. 안전하게 자율적.

03

컨텍스트를 주입해 맞춤형으로

CLAUDE.md · @멘션으로 프로젝트 맥락을 이해한다. 단순 생성기가 아니다.

이어지는 세 슬라이드에서 각 차별점을 ChatGPT와 직접 비교하며 자세히 봅니다.

DIFFERENTIATOR ① · 터미널에 산다

복붙 노가다, 5단계 → 1단계

× ChatGPT 방식 · 5단계
1. 채팅창에 "Todo 앱 만들어줘"
2. AI가 코드를 텍스트로 출력
3. 코드 블록을 하나씩 복사
4. 에디터로 가서 새 파일 만들고 붙여넣기
5. 저장 → 실행 → 에러 → 다시 1번부터

매번 "사람이 옮겨주는" 단계가 끼어듦. 시간·실수·집중력 손실.

✓ Claude Code 방식 · 1단계
> Todo 앱 만들어줘
✓ app.html 생성
✓ style.css 생성
✓ script.js 생성
→ app.html을 더블클릭해 브라우저로 확인

AI가 직접 파일을 만들고 저장. 사람은 지시·검토만. 복붙 0회.

DIFFERENTIATOR ② · 안전장치

위험한 일은 매번 물어본다

언제 물어보는가

  • 파일 쓰기·삭제 — 내용 변경
  • 셸 명령 실행 — git, npm 등
  • 네트워크 호출 — API, 다운로드
  • 새 의존성 설치 — npm install 류
Permission Prompt
> package.json 수정해줘⚠ Claude wants to edit: package.json[ Allow once / Always allow / Deny ]

"always allow"를 무지성으로 누르지 말 것. 최소 한 줄은 읽고 승인. 이 습관이 사고 예방의 90%.

DIFFERENTIATOR ③ · 컨텍스트 인식

프로젝트 맥락을 이해한다

CLAUDE.md · 프로젝트 룰북

프로젝트 루트 파일 — 매 세션 자동 주입.

  • "사이트 색은 주황으로 통일"
  • "말투는 늘 존댓말로"
  • 한 번 적어두면 매번 설명 X

@멘션 · 특정 파일 가리키기

대화 중 파일·폴더를 컨텍스트에 끼워 넣음.

  • @index.html — 내 홈페이지 봐줘
  • @imgs/ — 사진 폴더 봐줘
  • 파일 내용을 붙여넣을 필요 X

ChatGPT도 메모리·Projects 기능이 있지만, Claude Code는 폴더 안 CLAUDE.md를 매 세션 자동 주입 + @멘션으로 코드 파일을 직접 가리키기가 표준이라는 점이 차이입니다.

CLAUDE MODEL FAMILY

Haiku · Sonnet · Opus · Fable — 4가지 모델

Haiku 4.5

빠르고 가벼움 — 단순 작업·자동화·분류

  • 속도/품질: 매우 빠름 · 기본 OK
  • 비용: 가장 저렴
  • 용도: 반복 처리 · 분류 · 짧은 답변

Sonnet 5

균형 — 일상 코딩의 표준

  • 속도/품질: 빠름 · 거의 모든 작업 충분
  • 비용: 중간
  • 용도: 이 과정의 메인

Opus 5NEW

최고 품질 — 어려운 추론·복잡한 설계

  • 속도/품질: 느림 · 최상 (복잡 추론)
  • 비용: 비쌈
  • 2026.7 출시 · Plan Mode · 어려운 디버깅

Fable 5

최상위 — 가장 어려운 문제를 스스로 깊이 추론

  • 속도/품질: 느림 · 추론력 최강
  • 비용: 가장 비쌈
  • 2026.6 출시 · 최상위 요금 티어

/model 명령으로 세션 중 전환 가능. 강의 기본은 Sonnet, 비용 신경 쓰일 땐 Haiku, 진짜 막힐 때만 Opus. Fable은 계정·플랜에 따라 선택지에 없을 수 있어요 — 이 과정 실습은 Sonnet이면 충분합니다.

CAVEATS · 한계와 주의

한계도 알고 써야 합니다

⚠ 환각 (Hallucination)

없는 함수·사실을 만들어낸다

자신 있게 답하지만 실제로 없을 수 있음 → 코드 실행으로 검증.

⚠ 보안

비밀번호·API 키를 직접 입력 금지

컨텍스트에 들어간 값은 빠지지 않음 → 환경변수·.env로만.

⚠ 검증은 사람

"잘 됐다"는 말 — 한 번 더 확인

"성공"이라 해도 실제 안 돌아가는 경우 있음 → 직접 실행 확인.

⚠ 학습 데이터 한계

최신 라이브러리·API는 모를 수 있음

학습 시점 이후 정보 X → 공식 문서 링크 던지거나 @멘션.

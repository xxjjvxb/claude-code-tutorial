7장 — 상호작용 페이지

보기만 하는 페이지에서 — 로그인하고 저장되는 진짜 앱으로. 구글 로그인을 붙이고, 서브에이전트 셋과 "나만의 메모장"을 만들어 배포합니다. 도구: Google OAuth · Supabase · Claude Code 서브에이전트 · GitHub · Vercel.

DECK 1

구글 로그인

5장에서 만든 데이터 페이지에 진짜 구글 OAuth 로그인을 답니다. Google Cloud 설정 → 대화로 구현 → 로컬 확인 → Vercel 재배포(redirect URI)까지 — 자주 나는 로그인 에러 해결법 포함.

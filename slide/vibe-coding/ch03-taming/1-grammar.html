기호 하나에 한 가지 역할

@
파일 · 폴더 멘션
@app.html @tests/ 로 컨텍스트에 끼워 넣기
!
셸 명령 실행
!dir!ls 처럼 PowerShell셸을 즉석 호출
Esc
멈춤 · 되돌리기
한 번 = 멈춤 · 빈 입력에서 두 번 = 되돌리기 메뉴

/ @ !는 입력 첫 글자에서, Esc는 언제든 — 넷 다 저절로 손이 가야 합니다.

SLASH · 운영형 6가지

슬래시 — 지금 새로 배울 6개

/init
현재 폴더 분석 → CLAUDE.md 자동 초안 생성
/agents
서브 에이전트 안내 — 만들기는 말로 부탁, 5장에서 본격
/model
Haiku · Sonnet · Opus 전환 — 한 명령
/memory
CLAUDE.md 직접 보기 · 편집 진입
/compact
컨텍스트 요약 — /clear보다 부드러움 (다음 덱)
/permissions
권한 설정 보기 · 편집 (다음 덱)

1장에서 /help · /clear · /usage · /resume 4개를 익혔고, 여기서 6개 추가 → 총 10개가 손에 들어옵니다.

/INIT — 가장 자주 첫 명령

새 폴더 들어가면
/init 부터.

현재 폴더의 파일 구조 · 코드를 Claude가 훑은 뒤 CLAUDE.md 초안을 자동 생성. 거기서부터 본인 입맛대로 다듬으면 끝.

1폴더 진입 → claude 실행
2/init 입력 → 30초~2분 분석
3CLAUDE.md 생성됨 → 한국어 답변 등 추가
@ MENTION — 컨텍스트에 끼워 넣기

"이 파일 좀 봐줘"의 정식 표현.

파일 내용을 매번 복사·붙여넣기 할 필요 없음. @로 가리키기만 하면 Claude가 그 파일을 직접 읽어서 답변에 반영합니다.

파일@index.html — 그 파일 한 개
폴더@tests/ — 폴더 안 모든 파일
자동완성@ 친 뒤 Tab — 폴더 트리에서 선택
! SHELL — 셸 명령 즉석 실행

claude를 나가지 않고 PowerShell셸 명령.

대화 중간에 셸 명령을 한 번 돌리고 싶을 때. !로 시작하면 그 줄은 PowerShell이셸이 직접 실행. 결과는 다음 응답에 자동 포함됩니다.

자주!dir!ls · !code --version
주의처음 쓸 땐 권한 prompt — 한 번 read해보고 승인
결과 활용"방금 실행한 결과 보고 분석해줘" 가능
MEMORY — 규칙 남기기

"기억해줘" 한마디로 CLAUDE.md에 기록.

대화 중 "앞으로는 이렇게 해줘" 규칙을 남기고 싶을 때 — 그냥 말하고 "기억해줘"를 붙이면 Claude가 CLAUDE.md에 적어 둡니다. /memory로 언제든 확인.

규칙항상 한국어로 답해줘. 기억해줘
스타일들여쓰기는 스페이스 4칸으로. 기억해줘
확인/memory — 저장된 규칙 열람

STEP 01 · / 슬래시

/model 로 모델 전환

해보기

  1. 홈페이지 폴더에서 claude 실행
  2. /model 입력 → 엔터
  3. 리스트에서 Haiku 선택
  4. "안녕" 한 번 → 응답 속도 체감
  5. 다시 /model → Sonnet으로 복귀
claude — my-intro/
> /model Select a model: > haiku (빠르고 저렴) sonnet (현재) ← 강의 기본 opus (느리지만 똑똑) ✓ haiku 로 변경됨> 안녕 안녕하세요! (응답이 더 빠름)

Haiku는 짧은 답변·반복 작업에. 강의 기본은 Sonnet — 다 끝나면 Sonnet으로 돌려놓고 다음 단계로.

STEP 02 · @ 멘션

@index.html 분석 시키기

실험할 것

  1. claude 입력란에 @ 입력
  2. Tab 누르면 폴더 트리 자동완성
  3. index.html 선택 → 한 칸 띄고 "분석해줘"
  4. 결과: 디자인 톤·구조 분석 응답

변형 시도

  • @style.css 색상 팔레트 정리해줘
  • @index.html 글자 좀 키워줘
  • @. — 현재 폴더 전체 컨텍스트

@ 자동완성에 익숙해지면 매번 파일 경로 외울 필요가 없어집니다 — Tab만 누르면 됨.

STEP 03 · ! 셸 실행

대화 중간에 PowerShell셸 명령 호출

claude — my-intro/
# 1) 셸 명령 즉석 실행> !dir!ls ⚠ Claude wants to run: dirls [ Allow once / Always allow / Deny ] → "Allow once" 선택 $ dirls index.html style.css CLAUDE.md# 2) 그 결과 활용> 방금 목록 보고, 다음 작업 제안해줘 홈페이지 기본 파일은 다 있습니다. 다음으로: · style.css에 hover 효과 추가 · 사진(photo.jpg) 최적화

처음 !를 쓰면 권한 prompt가 뜹니다 — "Allow once"가 가장 안전. "Always allow"는 나중에 신뢰가 쌓인 명령에만.

STEP 04 · 메모리

CLAUDE.md에 한국어 규칙 추가

3개 추가해보기

  1. 항상 한국어로 답해줘. 기억해줘
  2. 코드 블록은 마크다운으로 써줘. 기억해줘
  3. 변수명은 영어, 주석은 한국어로. 기억해줘

Claude의 답에서 my-intro/CLAUDE.md에 적었는지 확인.

확인

  • VS Code 사이드바에서 CLAUDE.md 열기
  • 방금 추가한 3줄 보임
  • /memory 명령으로도 진입 가능
  • 한 번 적은 규칙은 매 세션 자동 주입

CLAUDE.md는 200줄 넘기면 신호대잡음비 ↓ — 짧고 명확한 규칙만 적습니다 (이 장 뒤 덱에서 자세히).

STEP 05 · 되돌리기

AI가 망쳤을 때 — ESC 두 번

ESC 두 번이 하는 일

  • 입력창이 빈 상태에서 ESC를 두 번 누르기
  • 되돌리기 메뉴(rewind)가 열림 — 돌아갈 시점 선택
  • 코드만 · 대화만 · 둘 다 — 복원 범위도 선택
  • /rewind 명령으로도 같은 메뉴

한계 — 알아둘 것

  • Claude가 편집한 파일만 되돌림
  • 본인이 직접 고친 것 · 터미널 명령 결과는 대상 아님
  • 더 강력한 되돌리기(어떤 변경이든 시점 복원)는 3장 Git에서 배웁니다

일부러 "제목 색을 이상하게 바꿔줘" 시킨 뒤 — ESC 두 번으로 원복해 보세요. 되돌릴 수 있다는 감각이 이 실습의 목표입니다.

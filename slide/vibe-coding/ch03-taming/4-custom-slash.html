OVERVIEW · 이 덱의 흐름

이 덱은 4단계 — 왜 → 만들고 → 부르고 → 다듬기

01

왜 필요한가

같은 부탁을 매번 다시 치는 낭비 — 명령으로 굳힌다.

02

만들기

commands 폴더에 .md 파일 한 장 — 이름이 곧 명령.

03

부르기

/ 치면 자동완성 목록 — 따로 등록할 필요 없음.

04

실습 — /asdf

직접 만들고 5번 써보며 다듬는다.

먼저 — 자주 하는 부탁을 내가 만든 단축 명령으로 굳힙니다. 대화 없이 한 줄로 실행하는 claude -p(헤드리스)는 부록에서 다룹니다.

SLASH · 또 하나의 내 명령

커스텀 슬래시 — 자주 하는 부탁을 한 단어로

왜 + 어디에

"방금 뭘 한 거야? 쉽게 정리해줘" — 같은 부탁을 매번 다시 칩니다. 한 번 적어 명령으로 굳히면 됩니다.

  • .md 파일 이름이 곧 명령 — asdf.md → /asdf
  • 개인 폴더 %USERPROFILE%\.claude\commands~/.claude/commands 에 두면 — 어떤 프로젝트에서나
  • 프로젝트 폴더의 .claude\commands.claude/commands 는 — 그 프로젝트 안에서만
.claude\commands\asdf.md.claude/commands/asdf.md 
나는 비개발자라 잘 모르겠어.
방금 한 대답을 — 딱 3줄로 요약.
1줄: 방금 네가 뭘 했는지
2줄: 지금 어떤 상태인지
3줄: 내가 이제 뭘 하면 되는지

/asdf처럼 어디서나 쓸 명령은 — 개인 폴더에 한 번만 만들어 두면, 프로젝트에 상관없이 모든 곳에서 그대로 불러 씁니다.

INSIDE · 안에 적는 것

파일 안에는 — 평소 치던 부탁 그대로

본문

시킬 일을 사람 말로

평소 Claude에게 치던 그 문장 그대로. 어려운 용어 필요 없음 — "쉽게 정리해줘"면 충분.

또렷이

원하는 모습을 콕 집어

"딱 3줄로", "번호로", "내가 할 일만" — 답이 어떻게 나오면 좋을지 적어두면 매번 그렇게.

하나만

한 가지 일에 집중

슬래시 하나는 한 가지 일만 — 너무 많이 시키면 결과가 흐려짐.

형식이 헷갈리면 — "방금 한 일을 3줄로 정리해주는 슬래시 명령 만들어줘"라고 Claude에게 시키면 파일까지 만들어 줍니다.

CANDIDATES · 쓸모 있는 후보 6

비개발자가 만들면 좋은 — 슬래시 6가지

/asdf ★

방금 한 거, 내가 뭘 하면 되는지 딱 3줄로.

/easy

방금 설명을 — 더 쉬운 말로 다시.

/next

"그래서 지금 내가 뭘 하면 돼?"

/check

지금까지 한 거, 문제 없는지 점검.

/oops

에러가 났어 — 무슨 일이고 어떻게 풀지.

/save

지금까지 한 일을 깔끔하게 저장(커밋).

정답은 없습니다 — "내가 이번 주에 3번 이상 친 부탁"이 가장 좋은 후보. /asdf는 이어지는 실습에서 함께 만들어 봅니다.

CALL · 부르는 법

호출은 — / 치면 자동완성

쓰는 법

  1. / 를 치면 — 만든 명령이 목록에 뜸
  2. /asdf 선택 — 적어둔 부탁이 그대로 실행
  3. Claude가 길게 답한 직후에 치면 가장 유용

기본 슬래시(/model·/init)와 같은 자리에 나란히.

claude · 슬래시 호출
> /asdf 1. 로그인 화면을 새로 만들었음 2. 아직 구글 연결은 안 됨 3. 브라우저에서 한 번 열어보세요

파일을 만들면 — 다음부터 / 목록에 자동으로 나타납니다. 따로 등록할 필요 없음.

실습 · 슬래시

/asdf 만들고 — 5번 써보며 다듬기

1

Claude에게 만들게 하기 — "방금 한 일과 내가 할 일을 3줄로 요약하는 /asdf 슬래시를, 어떤 프로젝트에서나 쓰게 만들어줘"

2

파일 확인 + 호출 — .claude/commands/asdf.md 읽어보고, 작업 뒤 /asdf 쳐보기

3

5번 써보며 다듬기 — 답이 길거나 아쉬우면 asdf.md 본문을 손본다

4

늘 딱 3줄이면 완성 — "무조건 3줄", "쉬운 말로" 같은 한 줄을 추가

이름은 마음대로 — 외우기보다 빨리 치기. 여기서 만든 /asdf는 남은 강의 내내 쓰게 됩니다.

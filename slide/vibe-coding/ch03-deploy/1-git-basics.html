PART A · GIT 안전벨트

Git — 망쳐도 되돌릴 수 있다

AI가 파일을 마음대로 고치는 시대일수록 버전 관리는 옵션이 아니라 필수. 명령 4개만 있으면 충분합니다.

DEFINITION · Git이 뭔가

코드의 시간여행 장치입니다.

파일이 어떻게 바뀌어 왔는지 기록하고, 원하는 시점으로 되돌릴 수 있는 도구. 여러 명이 같이 작업할 때도 충돌 없이 합쳐줍니다.

기록파일이 변할 때마다 스냅샷으로 저장
복원"3시간 전으로 돌려줘" — 한 줄이면 끝
협업여러 명의 변경을 충돌 없이 합치기
WHY · AI 시대의 Git

AI가 파일을 직접 고치는 시대 — 안전벨트입니다

× Git 없이 AI 시키기
"여러 파일 한꺼번에 수정해줘"
✓ 5개 파일 수정 완료
...어 뭔가 망가짐
어디부터 어디까지 바뀐 건지 모름
되돌릴 길이 없음

한 번 잘못 시키면 복구 불가. 손이 떨리면서 일을 시키게 됩니다.

✓ Git과 함께
git commit (직전 상태 저장)
"여러 파일 한꺼번에 수정해줘"
✓ 5개 파일 수정 완료
망가졌으면 → git restore .
5초 만에 직전으로 복귀

되돌릴 수 있다는 감각이 있을 때만 AI에게 큰 일을 맡길 수 있습니다.

CONCEPT · 헷갈리지 말 것

Git ≠ GitHub — 완전히 다른 것

Git · 도구 (내 컴퓨터에)

버전 관리 프로그램 자체

  • 내 컴퓨터에서 동작
  • 인터넷 없이도 됨
  • 명령어: git init, git commit
  • 오픈소스 · 누구나 무료
GitHub · 서비스 (인터넷에)

Git 저장소를 클라우드에 두는 곳

  • 웹사이트 — github.com
  • 여럿이 같은 코드를 공유
  • Microsoft 운영 (유료/무료)
  • "Git의 인스타" 같은 SNS 측면도

이 덱에서는 Git과 GitHub 가입까지 — 바로 다음 덱에서 GitHub에 push해 배포합니다.

CORE FLOW · 핵심 흐름

매일 쓰는 Git 명령은 딱 4개

01
init
한 번만. 폴더를 Git으로 추적 시작.
PS>$ git init
02
status
"지금 어떤 변화가 있나" 확인.
PS>$ git status
03
add
저장할 파일들을 모은다.
PS>$ git add .
04
commit
스냅샷 + 메시지로 영구 저장.
PS>$ git commit -m "메시지"

02 → 03 → 04 사이클이 매일 반복됩니다. 작업 한 덩어리 끝날 때마다 commit — 하루에 5–10번 정도.

DEEP · git init / git status

시작하고, 확인하는 명령

git init — 한 번만

현재 폴더를 Git이 추적하는 저장소로 만든다. 숨김 폴더 .git이 생성됨.

  • 이미 init된 폴더에 또 하면 → 그냥 무해함
  • .git 폴더 지우면 → 추적 끝
PowerShellTerminal (zsh) — my-intro/
git init Initialized empty Git repository in C:\Users\you\Desktop\my-intro\.git\/Users/you/Desktop/my-intro/.git/ git status On branch main No commits yet Untracked files: index.html style.css

git status는 막혔을 때 가장 먼저 치는 명령 — 지금 상태가 어떤지 알려줍니다.

DEEP · git add / git commit

변경사항을 스냅샷으로 저장

add — 저장할 파일 모으기

변경된 파일 중 커밋에 포함시킬 것들을 선별해서 staged 영역에 올린다.

  • git add . — 모든 변경 다 포함
  • git add index.html — 특정 파일만

commit — 영구 저장

staged 영역의 내용을 스냅샷으로 박제. 메시지 한 줄 필수.

  • -m "메시지"로 한 줄 설명
  • 좋은 메시지: "자기소개 페이지 첫 버전"
한 사이클 — add → commit
git add . git commit -m "자기소개 페이지 첫 버전" [main (root-commit) a3f1b2c] 자기소개 페이지 첫 버전 2 files changed, 124 insertions(+)
UNDO · 되돌리기

망친 파일 한 줄로 원복.

commit 이후의 변경을 직전 commit 상태로 되돌리는 명령. AI가 잘못 고친 직후 가장 자주 씁니다.

파일git restore index.html — 그 파일만
전부git restore . — 모든 변경 통째 취소
규칙commit하지 않은 변경은 한 번에 사라짐 — 신중히

CHECK · git 설치·신원 점검

시작 전 — git --version 한 번 확인

1장 셋업에서 이미 깔았죠?

Claude 설치 전에 git을 먼저 깔고 신원 등록까지 했습니다. 본 실습에 들어가기 전 두 가지를 빠르게 점검합니다.

  • git --version 출력 → 버전 숫자가 나오면 OK
  • git config --global user.name 출력 → 본인 이름이 나오면 OK
  • 둘 중 안 되는 게 있으면 — 오른쪽 박스 보고 보강
PowerShellTerminal (zsh) — 점검 2줄
# 1) 설치 확인 git --version git version 2.49.x# 2) 신원 등록 확인 git config --global user.name 홍길동# 안 됐으면 — 1장 셋업 STEP 03 다시# git config --global user.name "이름"# git config --global user.email "메일"

신원이 등록 안 되면 첫 커밋에서 *** Please tell me who you are 에러 — git config 두 줄로 해결, 평생 한 번만. 막히면 손드세요.

STEP 01 · git init

2장에서 만든 홈페이지 폴더를 Git 저장소로

3가지만 하면 됨

  1. VS Code → File → Open Folder → my-intro
  2. 통합 터미널 (Ctrl + `⌘ + J) 열기
  3. git init 입력 → 엔터
PowerShellTerminal (zsh) — my-intro/
git init Initialized empty Git repository in C:\Users\you\Desktop\my-intro\.git\/Users/you/Desktop/my-intro/.git/# 폴더에 숨김 .git 폴더가 생성됨# VS Code에서 좌측 사이드바에 변화

VS Code 좌측 사이드바에 Source Control 아이콘 (Y자 모양)이 활성화되면 성공. 거기서도 git을 GUI로 다룰 수 있습니다.

STEP 02 · 첫 커밋

status → add → commit 한 사이클

PowerShellTerminal (zsh) — my-intro/ — 첫 커밋 한 사이클
# 1) 지금 어떤 상태인지 git status Untracked files: index.html, style.css, CLAUDE.md# 2) 모든 변경 staged 영역에 올림 git add .# 3) 다시 status — staged 확인 git status Changes to be committed: new file: index.html, style.css, CLAUDE.md# 4) 커밋 — 메시지 한 줄 git commit -m "자기소개 페이지 첫 버전" [main (root-commit) a3f1b2c] 자기소개 페이지 첫 버전 3 files changed, 219 insertions(+)

커밋 메시지는 한국어 OK. "오늘 한 일을 한 줄로" 정도면 충분.

STEP 03 · AI에게 git 시키기

"지금까지 작업 커밋해줘"

프롬프트 
지금까지 작업 커밋해줘
claude — my-intro/
> 지금까지 작업 커밋해줘 변경 사항을 확인합니다. ⚠ Claude wants to run: git status → 승인 CLAUDE.md에 답변 규칙 3개 추가됨. 커밋 메시지를 제안드립니다: → "CLAUDE.md에 답변 규칙 추가" ⚠ Claude wants to run: git add . && git commit -m "..." → 메시지 OK? 승인 ✓ [main b8c9d4e] CLAUDE.md에 답변 규칙 추가 1 file changed, 4 insertions(+)

처음으로 AI가 본인 손 대신 git을 다루는 순간. 권한 prompt 뜨면 메시지 한 번 읽고 승인 — 무지성 X.

3장 — 홈페이지 외부 배포

내 컴퓨터에만 있던 홈페이지가 진짜 인터넷 주소를 갖습니다. Git 안전벨트를 채우고 → GitHub에 올려 → Vercel로 자동 배포. 도구: Git · GitHub · Vercel.

시작 전에 — 자기소개가 있는 폴더로

왜 그 폴더에서?

스킬은 — 지금 Claude가 켜진 폴더의 파일을 가지고 일합니다. 2장에서 만든 자기소개 index.html이 있는 폴더에서 시작해야 그 파일을 문서로 바꿀 수 있습니다.

  • 2장에서 index.html을 만든 폴더를 연다
  • 그 폴더 안에서 claude 실행
  • 새 폴더 말고 — 꼭 그 폴더에서
PowerShellTerminal (zsh) · 자기소개 폴더
# 자기소개를 만든 폴더로 이동 cd c:\lecture\my-intro# index.html 이 보이면 — 제대로 왔다 dir index.html style.css claude

폴더 위치가 기억 안 나면 — 2장에서 자기소개를 저장한 곳입니다. 탐색기에서 찾아 주소창의 경로를 복사해 cd 뒤에 붙여넣으면 됩니다.

INSTALL · 스킬 설치

스킬 설치 — 두 줄이면 끝

마켓플레이스에서 한 번에

공식 문서 스킬은 "마켓플레이스"에서 받습니다. document-skills 묶음 하나에 — PPTX·PDF·DOCX·XLSX가 다 들어 있습니다.

  1. 보관소 등록 — /plugin marketplace add
  2. 설치 — /plugin install document-skills
  3. 적용 — /reload-plugins (또는 claude 재시작)
  4. 메뉴가 뜨면 — 화살표로 골라 "Install" 해도 OK
claude · ① 보관소 등록 
/plugin marketplace add anthropics/skills
claude · ② 설치 
/plugin install document-skills@anthropic-agent-skills
claude · ③ 적용 
/reload-plugins

document-skills 한 번 설치로 4종 문서 능력이 전부 준비 끝. 설치 직후엔 /reload-plugins를 한 번 — 안 그러면 다음 claude 재시작까지 활성화가 안 됩니다. 명령이 헷갈리면 — Claude에게 "공식 문서 스킬 설치를 도와줘"라고 하면 이 과정을 대신 안내합니다.

MAKE A · 자기소개 → 워드

자기소개를 — 진짜 워드 문서로

이렇게 시킵니다

스킬을 따로 부르지 않아도 됩니다 — "워드 문서로 만들어줘"라고만 하면 Claude가 알아서 docx 스킬을 켭니다.

  • index.html을 가리키며 — "워드 문서로"
  • 제목·소제목이 갖춰진 .docx가 생성
  • 아쉬우면 — "제목 크게"처럼 한 줄로 다듬기
프롬프트 · 워드 만들기 
index.html 내용으로 자기소개 워드 문서(docx)를 만들어줘. 제목 + 소제목 구조로 정리해서.
프롬프트 · PDF로도 
이 자기소개를 PDF로도 만들어줘

만든 .docx는 더블클릭하면 Word에서 바로 열립니다. 한 번에 완벽하지 않아도 — 한 줄씩 고치면 됩니다.

MAKE B · 데이터 → 엑셀

손에 있는 목록을 — 엑셀 표로

데이터 → 표 → 수식까지

정리해 둔 목록·표를 그대로 엑셀로. 표만 만드는 게 아니라 합계·정렬 같은 수식까지 넣어줍니다.

  • md·txt로 적어둔 목록이 있으면 — 그 파일을 @로 지목
  • 없어도 OK — 아무 목록이나 표로 만들어 보기
  • 완성되면 더블클릭 — Excel에서 확인
프롬프트 · 엑셀 만들기 
@목록.md 내용을 표로 정리해서 엑셀(xlsx)로 만들어줘.
항목별로 시트에 정리하고, 개수 합계 셀도 넣어줘.

파일이 다른 폴더에 있으면 — 경로째 붙여넣거나 "바탕화면의 목록.md"처럼 말로 알려줘도 됩니다. 7장에서 크롤링으로 긁어온 데이터도 똑같은 방법으로 엑셀이 됩니다.

WOW · 진짜 파일이 나온다

코드 한 줄 없이 — 진짜 워드·엑셀이 툭.

"워드 문서로 만들어줘" 한 줄 → 더블클릭하면 Word에서 그대로 열리는 진짜 .docx. 엑셀은 수식까지. 코드를 한 줄도 안 썼는데 — 업무에 바로 쓰는 파일이 나옵니다.

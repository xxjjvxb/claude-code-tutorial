WHY & WHAT · MCP가 뭔가

다른 프로그램과 교류하는 통로.

Claude Code는 지금 열어둔 프로젝트 폴더 안만 봅니다. 그 밖의 파일·GitHub·웹 페이지엔 닿지 못해요. MCP는 담장 밖 프로그램과 교류하는 "공통 통로" — 연결 방식이 하나로 정해져 있어, 어떤 도구든 같은 방법으로 이을 수 있습니다.

한계기본은 열어둔 폴더 + 터미널까지
규격도구마다 다른 방식 X — 하나의 표준
교체필요한 도구만 꽂고 — 안 쓰면 뺀다
HOW · 연결하기

연결도 — Claude에게 부탁하면 끝

내가 할 일은 부탁 한 마디

연결 명령을 외울 필요 없습니다 — "○○ MCP 연결 도와줘"라고 말하면, 명령 찾기부터 연결 확인까지 Claude가 대신합니다.

프롬프트 · MCP 연결 부탁 
Playwright 브라우저 MCP 연결 도와줘.

실제로는 이런 일이 일어납니다

  • claude mcp add playwright -- npx @playwright/mcp@latest
  • claude mcp list — 연결 상태 확인
  • 안 쓰면 claude mcp remove로 뺀다

직접 치고 싶으면 오른쪽 명령 그대로 — 정확한 명령은 도구마다 달라서, 부탁이 가장 빠릅니다.

SAFETY · 권한 감각

읽기는 마음껏 — 쓰기·삭제는 한 번 멈춰서.

MCP는 외부 도구에 손을 댑니다. 읽어 오는 일은 거의 안전하지만, 파일을 바꾸거나 지우는 일은 — 2장에서 배운 권한 감각 그대로 신중하게.

읽기참고·조회·수집 — 부담 없이
쓰기수정·삭제 — 권한 prompt를 꼭 읽고
범위필요한 폴더·사이트만 다룬다

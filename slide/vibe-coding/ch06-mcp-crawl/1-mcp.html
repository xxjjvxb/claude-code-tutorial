6장 · MCP

MCP — 외부 세계와 연결하는 표준 포트

Claude는 기본적으로 내 프로젝트 폴더 안만 봅니다. MCP는 파일·GitHub·브라우저 같은 외부 도구를 꽂는 "표준 포트"입니다. 이 덱에서 MCP 개념과 연결을 익히고 — 다음 덱에서 브라우저 MCP로 웹을 직접 크롤링합니다.

WHY · 왜 필요한가

Claude 혼자선 — 담장 안만 본다.

Claude Code는 지금 열어둔 프로젝트 폴더를 다룹니다. 그 밖의 파일, GitHub 이슈, 인터넷 페이지는 — 연결해 주기 전엔 닿지 못합니다.

기본열어둔 폴더 + 터미널까지
한계외부 서비스·웹 페이지는 못 봄
MCP그 바깥 도구를 Claude에 연결해 준다
WHAT · MCP가 뭔가

MCP — 외부 도구를 꽂는 USB 포트.

예전엔 기기마다 다른 케이블이 필요했지만 USB 하나로 통일됐듯 — MCP는 "외부 도구를 AI에 연결하는 공통 규격"입니다. 한 방식만 알면 어떤 도구든 꽂을 수 있습니다.

규격도구마다 다른 방식 X — 하나의 표준
교체필요한 도구만 꽂고 — 안 쓰면 뺀다
내가 할 일"연결" 한 줄 — 쓰는 법은 Claude가
HOW · 연결은 한 줄

연결은 한 줄 — claude mcp add

내가 할 일은 "연결" 한 줄

도구를 한 번 꽂아 두면 — 쓰는 법은 Claude가 알아서. 명령을 외울 필요 없이 Claude에게 물어보면 됩니다.

  • claude mcp add <이름> -- <실행 명령> — 한 줄로 연결
  • claude mcp list — 연결 상태 확인
  • 안 쓰면 claude mcp remove로 뺀다
PowerShell터미널 · MCP 연결 
claude mcp add <이름> -- <실행 명령>
claude mcp list

정확한 연결 명령은 도구마다 다릅니다 — Claude에게 "○○ MCP 연결 도와줘"라고 물으면 명령까지 대신 알려줍니다. 브라우저(Playwright) 연결은 다음 덱에서 직접.

SAFETY · 권한 감각

읽기는 마음껏 — 쓰기·삭제는 한 번 멈춰서.

MCP는 외부 도구에 손을 댑니다. 읽어 오는 일은 거의 안전하지만, 파일을 바꾸거나 지우는 일은 — 2장에서 배운 권한 감각 그대로 신중하게.

읽기참고·조회·수집 — 부담 없이
쓰기수정·삭제 — 권한 prompt를 꼭 읽고
범위필요한 폴더·사이트만 다룬다

RECOVERY · git 되돌리기

망쳤을 때 — 한 줄 복구

git restore .

commit 안 한 모든 변경 → 직전 commit 상태로. 가장 자주 쓰는 한 줄.

git restore <file>

특정 파일만 되돌림. 다른 변경은 유지.

git reset --hard HEAD~1

직전 commit도 되돌림. 주의 — 이미 push했으면 X.

자주 commit하면 — 망쳐도 손해 작음. 2장의 "작은 단위 + 매번 commit"이 여기서 빛납니다. Claude가 망친 것도 손으로 풀지 말고 git restore . — 5초 만에 깨끗, 다시 작은 단위로.

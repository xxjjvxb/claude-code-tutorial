WORLD · 숨은 규칙

세상의 현상 뒤엔 — 보이지 않는 규칙이 있다.

햇빛이 강하면 기온이 오르고, 키가 크면 몸무게도 대체로 늘어납니다. 눈엔 안 보이지만 그 뒤엔 입력을 출력으로 바꾸는 하나의 규칙 — 함수가 있습니다.

입력온도 · 시간 · 거리 — 우리가 넣는 값
규칙그 둘을 잇는 함수 — 직접 못 봄
출력우리가 관찰하는 결과값
MEASURE · 관찰

규칙을 알려면 — 일단 재본다

측정 = 관찰

숨은 규칙은 직접 볼 수 없습니다. 우리가 할 수 있는 건 — 재보는 것.

  • 온도계를 본다 · 키를 잰다 · 시간을 적는다
  • 한 번 재면 (입력, 출력) 숫자 한 쌍이 남는다
  • 그게 데이터 점 하나

점을 모으면?

한 점은 한 순간일 뿐. 여러 번 재서 점을 잔뜩 모으면 —

  • 점들이 흩어진 모양에서 규칙의 윤곽이 보인다
  • 점이 많을수록 규칙 추정이 쉬워진다
  • 하지만 — 점 자체가 정확하지 않다

점을 많이 모으면 규칙이 보일 것 같지만 — 한 가지 문제가 있습니다. 측정한 점은 진짜 값이 아닙니다.

NOISE · 오차

같은 걸 두 번 재면 — 숫자가 다르다.

저울에 같은 사람이 두 번 올라가도 0.1kg씩 다르게 나옵니다. 손 떨림, 기계의 한계, 반올림 — 측정엔 늘 작은 흔들림이 섞입니다. 이 흔들림이 노이즈(noise).

원인손 떨림 · 기계 정밀도 · 반올림
결과잴 때마다 조금씩 다른 값
이름이 흔들림을 노이즈라 부른다
GAUSSIAN · 노이즈의 모양

오차는 보통 — 참값 근처에 모인다.

크게 틀리는 일은 드물고, 살짝 틀리는 일이 대부분. 측정값을 잔뜩 쌓으면 참값을 한가운데로 한 종 모양이 됩니다. 이게 가우시안(정규분포) 노이즈 — 외울 건 "가운데로 모인다" 하나뿐.

가운데참값 근처 — 가장 빽빽
가장자리멀어질수록 드물게
기억종 모양 한 덩어리 — 수식은 Claude가
DATA · 신호 + 노이즈

우리가 가진 데이터 = 진짜 + 흔들림.

매끄러운 진짜 곡선 위에 가우시안 흔들림이 얹히면, 점들이 곡선 주변에 흩뿌려집니다. 현실의 데이터는 늘 이렇게 생겼습니다 — 곡선은 노이즈에 가려 보이지 않습니다.

신호숨은 진짜 규칙 (곡선)
노이즈측정의 흔들림 (가우시안)
우리 눈둘이 합쳐진 — 흩어진 점들뿐
THE QUESTION · 머신러닝의 질문

흩어진 점만 보고 — 숨은 곡선을 되찾을 수 있을까?

진짜 곡선은 노이즈에 가려 안 보입니다. 점들만 주어졌을 때 그 뒤의 곡선을 추정하는 것 — 바로 이것이 머신러닝, 그리고 AI가 푸는 문제입니다.

주어진 것흩어진 점들 (데이터)
숨은 것진짜 곡선 (규칙)
목표점에서 곡선을 추정하기
REGRESSION · 회귀

회귀 = 점들을 가장 잘 지나는 곡선 찾기.

모든 점을 정확히 통과할 필요는 없습니다. 점들의 한가운데를 부드럽게 가로지르는 곡선 — 그게 숨은 진짜 규칙의 추정치입니다.

부드럽게점마다 출렁이지 않게

MODEL · 곡선의 모양 후보

곡선에도 종류가 있다 — 직선부터 구불구불까지

직선 (1차)

가장 단순. 쭉 뻗은 직선 — 곡선이 휘는 데이터는 못 따라감.

완만한 곡선 (2–3차)

한두 번 부드럽게 휨. 봉우리·골짜기 하나 정도를 잡아냄.

구불구불 (고차)

PITFALL · 두 가지 실패

곡선 고르기엔 양쪽 함정이 있다

함정 1 · 과소적합

곡선이 너무 단순하다

  • 직선처럼 — 데이터의 흐름을 못 따라감
  • 봉우리·골짜기를 통째로 놓침
  • 점들과 곡선이 멀리 떨어짐
  • 큰 흐름조차 못 잡은 상태
함정 2 · 과적합

곡선이 너무 복잡하다

  • 점을 하나하나 다 통과하려 함
  • 노이즈(우연한 흔들림)까지 따라 그림
  • 데이터엔 완벽 — 진짜 규칙엔 빗나감
  • 다음 슬라이드에서 자세히

정답은 둘 사이 어딘가 — 큰 흐름은 잡되 노이즈는 무시하는 곡선입니다.

EXTRAPOLATION · 데이터 밖

데이터가 없는 곳은 — 곡선도 모른다.

점들이 모인 구간 안에서는 추정이 제법 믿을 만합니다. 하지만 그 바깥으로 곡선을 연장하면(외삽), 특히 구불구불한 곡선은 엉뚱한 곳으로 튀어 오릅니다.

데이터 안내삽 — 비교적 안전
데이터 밖외삽 — 위험
복잡할수록더 크게, 더 빨리 빗나감
LIMIT · 회귀의 한계

회귀로 안 잡히는 — 더 복잡한 규칙

회귀가 잘 맞을 때

규칙의 모양이 비교적 단순할 때 — 곡선 종류 몇 개만 시도하면 충분합니다.

  • 입력이 하나 (x 하나 → y 하나)
  • 봉우리·골짜기가 한두 개
  • 적당한 차수의 곡선이면 잡힘

한계가 오는 때

규칙이 복잡해지면 — "곡선 종류를 사람이 고르는" 방식이 벅차집니다.

  • 입력이 여럿 (키 + 나이 + 운동량 → 몸무게)
  • 규칙이 아주 구불구불할 때
  • 어떤 곡선을 골라야 할지조차 모를 때

이럴 땐 — 곡선 종류를 미리 고르지 않아도 되는, 훨씬 유연한 도구가 필요합니다. 그게 신경망.

NEURAL NET · 개념만

신경망 = 거의 어떤 곡선이든 흉내내는 함수.

작은 계산 단위(뉴런)를 층층이 쌓아 입력을 출력으로 바꾸는 하나의 거대한 함수입니다. 회귀처럼 곡선 종류를 미리 정하지 않아도, 데이터에 맞춰 모양을 스스로 잡습니다. 여기서는 개념만 — 코드는 짜지 않습니다.

뉴런작은 계산 한 칸
층(layer)쌓을수록 유연함 ↑
본질여전히 입력 → 출력 함수

  • 매우 유연 — 복잡한 규칙도
  • 데이터가 많이 필요 · 과적합 위험 ↑
  • 여기선 — 개념만

본질은 똑같습니다 — 데이터에서 숨은 함수를 추정하는 것. 신경망은 회귀의 "거대하고 유연한 버전".

고른 차수로 최종 추정 곡선을 그립니다.

  • "고른 차수로 최종 추정 곡선을 my_estimate_1.png로 깔끔하게 그려줘"
  • 이 그림이 — 내가 추측한 "진짜 함수"

정답 곡선은 아직 비밀 — 본인 눈으로 "제일 그럴듯한" 곡선을 고르세요. 점을 다 지나는 게 정답이 아닙니다.

실습 · STEP 6

데이터 밖으로 — 곡선을 늘려본다

이렇게 시켜보기

데이터가 끝나는 지점 너머로 곡선을 연장해 봅니다.

  • "내 곡선을 x가 10보다 큰 구간까지 늘려 그려줘"
  • "데이터 없는 곳에서 곡선이 어떻게 행동해?"

무엇을 관찰하나

데이터 구간 안과 밖에서 곡선이 어떻게 달라지는지 봅니다.

  • 데이터 끝을 지나며 — 부드럽나? 폭주하나?
  • 차수가 높을수록 더 심하게 튐
  • 이게 외삽의 위험

데이터가 없는 곳의 추정은 못 믿습니다 — 정답 공개 때 이게 왜 중요한지 눈으로 드러납니다.

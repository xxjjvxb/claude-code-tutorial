HEADLESS · 헤드리스

헤드리스 — 대화 없이 명령 한 줄로.

평소엔 Claude와 대화하지만, claude -p "..."는 대화창을 열지 않고 한 번의 요청을 즉시 처리하고 끝냅니다. 여기서는 각자 직접 써 보고 — 작업 스케줄러launchd · cron로 자동 실행까지 합니다.

한 줄요청 → 결과 → 종료. 대화 없음
자동화작업 스케줄러launchd · cron에 걸어 — 사람 없이 실행
실습직접 쳐 보고 — 5분마다 자동까지
실습 · 각자 직접

지금 바로 — claude -p 한 줄 쳐 보기

다 같이 한 번

  1. PowerShell터미널을 연다
  2. claude -p 뒤에 따옴표로 부탁을 적는다
  3. 엔터 — 대화창 없이 결과만 바로 나온다

5분마다 자동으로 받을 거니 — 받고 싶은 걸 골라보세요.

PowerShellTerminal (zsh) · headless
claude -p "나를 아주 신나게 칭찬해줘" 오늘 여기까지 온 것만으로 충분히 멋져요 — 계속 가요!# 대화창 없이 바로 끝

받고 싶은 것 — 특정 주가, 나를 향한 칭찬, 오후 5시까지 남은 시간. 이 중 하나를 5분마다 받게 만들어 봅니다.

AUTO · 작업 스케줄러launchd · cron

5분마다 — 알아서 실행되게

먼저 — 폴더 하나

작업이 돌아갈 기본 폴더를 만듭니다.

  • c:\lecture\headless~/lecture/headless 폴더 생성
  • 여기서 claude가 실행되고
  • 결과 기록(log.txt)도 여기 쌓임

작업 스케줄러에 등록할 3가지

  • 트리거 — 언제: 5분마다
  • 동작 — 무엇을: PowerShell로 claude 실행
  • 시작 위치 — 어디서: 위 headless 폴더

시작 옆 검색창에 작업 스케줄러를 입력해 열고 → 오른쪽 작업 만들기…를 클릭합니다.

launchd 또는 crontab에 등록할 3가지

  • 주기 — 언제: 5분마다 (StartInterval=300 또는 */5 * * * *)
  • 실행 명령 — 무엇을: claude -p "..."
  • 작업 디렉토리 — 어디서: 위 headless 폴더 (WorkingDirectory)

손쉬운 방법: 터미널에서 crontab -e. 정식 방법: ~/Library/LaunchAgents/에 plist.

3장의 Hooks가 "이벤트가 일어나면" 자동이었다면 — 작업 스케줄러launchd · cron는 "정해둔 시각이 되면" 자동입니다.

SCREENS · 작업 스케줄러 두 탭Mac은 화면 없이

두 개의 탭 — 트리거·동작을 채운다

Mac은 화면 없이 — crontab 한 줄

Mac엔 이 화면이 없습니다

작업 스케줄러는 윈도우 전용 GUI예요. Mac은 다음 화면의 crontab -e 한 줄이 등록의 전부 — 넘겨볼 화면이 따로 없습니다.

화면이 낯설면 — 그 화면을 그대로 캡처해 Claude에게 "여기서 5분마다 반복은 어디서 켜?"라고 물어보세요.

SETUP · 새 동작 만들기

"새 동작 만들기" — 세 칸을 이렇게 채운다

동작(I) 드롭다운은 "프로그램 시작" — 그 아래 세 칸을 화면 그대로 채웁니다.

Mac은 GUI가 없으니 crontab -e 한 줄로 등록합니다. 아래 박스의 한 줄을 그대로 붙여넣고 저장하면 끝.

① 프로그램/스크립트(P)
powershell
claude가 아니라 powershell — System32에 있어 이름만 적어도 윈도우가 찾습니다.
② 인수 추가(옵션)(A)
-NoExit -Command "claude -p '오후 5시까지 몇 분 남았는지 알려주고 log.txt에 한 줄 기록해줘'"
-NoExit = 실행 뒤 창이 안 닫힘. 바깥은 큰따옴표 ", claude 프롬프트는 작은따옴표 '. 프롬프트만 바꾸면 칭찬·주가 버전도 됩니다.
③ 시작 위치(옵션)(T)
c:\lecture\headless
여기서 claude가 실행되고 — log.txt 기록도 이 폴더에 쌓입니다. 따옴표 없이 경로만.
터미널 · crontab -e 
*/5 * * * * cd ~/lecture/headless && claude -p '오후 5시까지 몇 분 남았는지 알려주고 log.txt에 한 줄 기록해줘' >> log.txt 2>&1

*/5 * * * * = 5분마다. cd로 폴더 이동 후 claude 실행, 결과는 log.txt에 append. 첫 등록 시 개인정보 → 전체 디스크 접근 허용이 한 번 떠요.

세 칸을 다 채웠으면 — "확인"으로 저장. 막히는 부분이 있으면 화면을 캡처해 Claude에게 보여주며 물어보세요.

터미널에서 crontab -e → 위 한 줄 붙여넣기 → ESC + :wq 저장. 등록 확인은 crontab -l. 막히면 화면 캡처해 Claude에게.

WOW · 5분마다

5분마다 — Claude가 말을 건다.

등록해 두면 5분마다 PowerShell 창이 떠 Claude가 답을 보여줍니다. -NoExit라 창이 안 닫혀 바로 읽고, log.txt엔 기록이 차곡차곡 쌓입니다.

등록해 두면 5분마다 cron이 Claude를 호출합니다. 백그라운드 실행이라 창은 안 뜨지만 log.txt엔 기록이 차곡차곡 쌓입니다 — tail -f log.txt로 실시간 관찰.

창-NoExit — 결과가 눈앞에 그대로 남는다
기록headless 폴더의 log.txt 에 history
관찰5시까지 5분마다 — 같이 카운트다운
실습 · 헤드리스 자동화

폴더 → claude -p → 5분마다 등록

1

기본 폴더 만들기 — c:\lecture\headless~/lecture/headless

2

3

작업 스케줄러에 등록crontab -e 한 줄 등록 — 5분마다 실행되게. 어렵다면 Claude와 함께 — 화면을 보여주며 물어보기

4

5분 기다려 확인 — 창이 뜨는지, log.txt가 쌓이는지

5분마다는 데모용 설정입니다 — 확인이 끝나면 작업 스케줄러에서 이 작업을 끄거나 지우세요crontab -e에서 해당 줄을 지우세요.

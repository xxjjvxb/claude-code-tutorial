A · 미니 빌드 마무리

Plan 모드로 — 남은 기능 한 사이클

1

미니 폴더 → claude → /memory로 CLAUDE.md 확인

2

남은 기능 1개 — Plan 모드 (Shift+Tab 두 번) → 계획 → 승인 → 실행

3

test-writer 호출 — 새 기능에 테스트 자동 작성

4

실제 동작 확인 — 본인 손으로 한 번 (검증은 사람)

5

git commit + /usage 캡처

"1개 기능 추가"가 한도 — 발표 직전 큰 변경은 위험. 오늘은 안정화 위주.

A · 7 도구 활용

한 사이클에 — 5~7 도구 등장

claude · my-budget/ — 전 과정 도구 종합
# 1) CLAUDE.md 자동 주입 (3장) ✓ 한국어 답변 룰 적용# 2) Plan 모드 (4장) [plan]# 3) @ 멘션 (2장)> @routes/transactions.py 페이지네이션 추가# 4) Sub-agent (5장) → @test-writer 호출 자동# 5) MCP filesystem (6장) → tests/ 폴더 스캔# 6) 응답 끝 → Stop Hook (3장) → Telegram 알림 발송# 7) /review 슬래시 (3장)> /review

한 작업에 5~7 도구가 자연스럽게 결합. "군단 + 도구 + 자동화"의 진가.

B · design.md 작성

본인 디자인 룰 — 15줄 이내

design.md 
# my-budget · 디자인

## 컬러
- primary: #2563eb (블루)
- background: #f8fafc
- text: #1e293b

## 폰트
- Pretendard (한국어 우선)
- 제목 굵게 32pt · 본문 보통 16pt

## 레이아웃
- 16:9 비율
- 한 슬라이드 1 메시지
- 좌측 정렬 · 여백 16% 이상

위 내용을 복사해 프로젝트 루트에 design.md로 저장 — 본인 톤에 맞춰 컬러만 바꾸면 됩니다. 가계부면 신뢰감 있는 블루, 일기 앱이면 따뜻한 베이지.

B · 검증 + 미세 조정

✓

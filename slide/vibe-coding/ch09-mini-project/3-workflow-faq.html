PATTERN 01 · 테스트 먼저 시키기

"이 함수에 테스트부터" → "그 테스트 통과시켜줘"

TDD의 AI 시대 버전. 사람이 의도를 테스트로 표현 → AI가 그걸 만족하는 코드 생성. 검증이 자동.

단계 1"add_transaction에 pytest 테스트 짜줘 — happy + edge"
단계 2테스트 한 번 읽고 — 의도와 일치하는지 확인
단계 3"이제 그 테스트 통과시키는 함수 구현"
PATTERN 02 · 정리해달라기

"정리해줘" 한 줄 = 리팩터링

코드가 너저분해졌을 때. "리팩터링" 같은 전문 용어 X — "정리해줘"가 더 자연스럽고 효과적.

예시"@routes/transactions.py 정리해줘 — 기능 그대로"
결과긴 함수 분리 · 중복 제거 · 변수명 명확화
필수"기능 그대로" — 동작 변경 X 명시. Plan 모드 권장

ORCA · 에이전트 여러 개

에이전트를 나란히 돌린다 — 워크트리.

Orca의 대표 기능 — 프로젝트의 격리된 복사본(워크트리)을 여러 개 만들어, 각 에이전트가 서로 방해 없이 동시에 일하게 합니다. "A안·B안을 동시에 시켜보고 마음에 드는 쪽만 채택"이 가능해집니다.

격리워크트리마다 파일이 분리 — 서로 안 덮어씀
병렬기능 A와 버그 수정 B를 동시에 진행
채택결과를 비교해 좋은 쪽만 합치기

FAQ · 자주 부딪히는 7

과정 후에도 마주칠 — 7가지

01
claude 명령이 안 잡힘
PowerShell터미널 새로 → PATH 갱신. 안 되면 시작 메뉴Spotlight에서 다시 검색해 실행.
02
한국어 답변이 가끔 영어로
CLAUDE.md에 "한국어로 답해줘" 적었는지 확인. /memory로 체크.
03
좌하단 사용량이 갑자기 ↑
컨텍스트 길어진 것. /clear 또는 /compact.
04
Plan 모드 진입 안 됨
Shift+Tab을 두 번 — 한 번이 아닌. 헷갈리면 4장 Plan 덱 다시 보기.
05
Hook이 발동 안 함
claude 재시작 안 했음. settings.json 변경 후엔 무조건 /exit → claude.

2개 더 다음 슬라이드. 본인 케이스가 없으면 단톡방 — 다른 수강생도 비슷한 일 있음.

FAQ · 자주 부딪히는 7 (계속)

나머지 2가지

06
Sub-agent가 호출 안 됨
.md 파일 frontmatter 형식 확인 (--- 위아래). description이 적절해야 자동 호출. 명시 호출 @<name>도 OK.

claude mcp list로 확인. npx 패키지 다시 다운로드 시도. 방화벽·Node.js 버전도 의심.

TOOLS · 두 도구

PySide로 창을 그리고, PyInstaller로 묶는다

PySide6 — 창을 그린다

파이썬으로 창·버튼·입력칸을 그리는 도구. Qt라는 유명한 GUI 도구의 파이썬 버전.

  • "이 버튼을 누르면 ~" 만 짜면 됨
  • 코드는 Claude가 — 우리는 무엇을 만들지만
  • 운영체제 그대로의 모양 — 윈도우다움맥다움

PyInstaller — .exe.app로 묶는다

파이썬으로 만든 .py 파일을 .exe.app 한 덩어리로 묶어줍니다. 파이썬이 없는 PC에서도 그대로 동작.

  • 명령 한 줄 — pyinstaller --onefile --windowed
  • 한 번 묶는 데 1~2분 — 시간이 좀 걸림
  • 파일 하나로 친구한테 보내기 (같은 OS끼리)

둘 다 명령 한 줄로 설치. 코드는 Claude가 씁니다 — 우리는 무엇을, 어떻게 동작할지만 말합니다.

BUILD · .exe.app로 묶기

PyInstaller — 한 줄로 .exe.app 완성

실제로 일어나는 일 (참고)

claude가 대신 치는 명령은 pyinstaller --onefile --windowed pet.py — 진행 메시지가 쏟아져도 가만히 1~2분.

  • 결과는 dist\pet.exedist/pet.app 하나 — 성격 파일(CLAUDE.md)도 옆에 복사
  • 같은 OS의 다른 PC에 옮겨도 동작 — 파이썬 없어도. (Win↔Mac은 따로 빌드)
  • --onefile = 한 덩어리, --onedir = 폴더로 분산(더 빠른 실행) · --windowed = 실행 시 검은 콘솔 창 안 뜨게 (완성본은 켜기)
claude에게 · .exe.app 만들기 부탁 
pet.py를 PyInstaller로 더블클릭해 실행되는 .exe.app 한 덩어리로 만들어줘. 성격 파일 CLAUDE.md도 결과물 옆에 복사해줘. 끝나면 실행해서 보여줘.

명령·옵션은 외울 필요 없습니다 — 왼쪽 카드는 claude가 대신 쳐 주는 실제 명령(참고)입니다. Mac은 본인이 만든 앱이라 자체 서명 한 줄을 같이 시키면 깔끔 — codesign --deep --force --sign - dist/pet.app.

⚠ SAFETY · 처음 켤 때

경고창이 뜬다 — 정상이다.

내가 만든 .exe는 "서명"이 없어 Windows가 한 번 멈춰 묻습니다. 모르는 인터넷 .exe였다면 조심할 일이지만, 방금 내가 만든 거니 — "추가 정보" → "실행".

TROUBLE · 막힐 때 체크

자주 걸리는 — 5가지 + 해법

01
"pyside6를 찾을 수 없다"
pip 설치가 안 됐거나 다른 파이썬을 쓰는 중. pippip3 install pyside6를 그 PowerShell터미널 창에서 한 번 더.
02
펫을 눌러도 말이 없다
첫 마디는 5~20초 — "…생각 중"이면 기다리면 됩니다. 계속 조용하면 PowerShell터미널에서 claude -p "안녕"부터 — 로그인·인터넷 문제면 여기서 걸립니다.
03
.py가 안 뜨거나 — 빌드 에러
pythonpython3 pet.py를 PowerShell터미널에서 직접 실행하면 에러가 남음 → 빨간 줄을 통째로 복사해 Claude에게. 빌드 에러도 같은 방법.
04
.exe 더블클릭했더니 "Windows의 PC 보호"
정상. "추가 정보 → 실행". 슬라이드 13 참고.
04
.app 더블클릭했더니 Gatekeeper 차단
정상. Finder에서 우클릭 → 열기(1회). 또는 자체 서명: codesign --deep --force --sign - dist/pet.app. 슬라이드 13 참고.
05
.exe가 백신에 격리됐다
서명 없는 새 파일이라 가끔 오탐. Windows 보안 → 보호 기록 → 복원. 작업 폴더를 Defender 예외에 추가해두면 재발 방지.
05
"손상된 파일이라 열 수 없습니다"
실제 손상이 아니라 격리 속성 때문. xattr -dr com.apple.quarantine dist/pet.app 한 줄로 풀림. (다운로드한 앱에 macOS가 붙이는 속성)

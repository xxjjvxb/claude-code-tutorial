## 6. 평가 방법론 메모

- 각 Day 파일은 슬라이드별 1-line 등급(S/A+/A/B/F) + B 이하만 풀 포맷(Death Metrics + Divine Intervention) 평가.
- 등급 기준:
  - **S**: 그대로 keep — 강의 대표 컷 후보
  - **A+**: 거의 완벽 — 미세 조정만
  - **A**: 우수 — 합격선
  - **B**: 개선 필요 — 풀 포맷으로 처방
  - **F**: 즉결처형 — 컷 또는 전면 재작성
- 색상 코드는 강의 토큰 (`#fe6e00` primary, `#cc5a14` primary-fill, `#fcfaf7` background, `#423d38` on-surface, `#797067` on-surface-muted) 기준.

B · CLAUDE.md 작성 시작

B · 검증 — 작동하나

CLAUDE.md를 진짜 적용되는지 확인

검증 방법

  1. CLAUDE.md 저장 후 /exit → claude 재시작
  2. /memory로 현재 적용 룰 확인
  3. "먼저 너 자기소개 해봐" — 한국어로 오는지
  4. "라우트 추가해줘" — routes/에 자동 분리하는지

예상 동작

  • 모든 답변이 자동으로 한국어
  • 새 라우트 → routes/ 폴더 안에 생성
  • 들여쓰기 4칸 · snake_case 변수명
  • "먼저 plan부터" 같은 룰도 자동 따름

검증 후 commit — git commit -m "CLAUDE.md 초안 작성". 미니프로젝트의 첫 커밋입니다.

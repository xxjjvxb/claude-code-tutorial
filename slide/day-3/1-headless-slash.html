HEADLESS · 헤드리스

헤드리스 — 대화 없이 명령 한 줄로.

평소엔 Claude와 대화하지만, claude -p "..."는 대화창을 열지 않고 한 번의 요청을 즉시 처리하고 끝냅니다. 오늘은 각자 직접 써 보고 — 작업 스케줄러로 자동 실행까지 합니다.

한 줄요청 → 결과 → 종료. 대화 없음
자동화작업 스케줄러에 걸어 — 사람 없이 실행
오늘직접 쳐 보고 — 5분마다 자동까지
실습 · 각자 직접

지금 바로 — claude -p 한 줄 쳐 보기

다 같이 한 번

  1. PowerShell을 연다
  2. claude -p 뒤에 따옴표로 부탁을 적는다
  3. 엔터 — 대화창 없이 결과만 바로 나온다

5분마다 자동으로 받을 거니 — 받고 싶은 걸 골라보세요.

PowerShell · headless
PS> claude -p "나를 아주 신나게 칭찬해줘" 오늘 여기까지 온 것만으로 충분히 멋져요 — 계속 가요!# 대화창 없이 바로 끝

받고 싶은 것 — 특정 주가, 나를 향한 칭찬, 오후 5시까지 남은 시간. 이 중 하나를 5분마다 받게 만들어 봅니다.

AUTO · 작업 스케줄러

5분마다 — 알아서 실행되게

먼저 — 폴더 하나

작업이 돌아갈 기본 폴더를 만듭니다.

  • c:\lecture\day3\headless 폴더 생성
  • 여기서 claude가 실행되고
  • 결과 기록(log.txt)도 여기 쌓임

작업 스케줄러에 등록할 3가지

  • 트리거 — 언제: 5분마다
  • 동작 — 무엇을: PowerShell로 claude 실행
  • 시작 위치 — 어디서: 위 headless 폴더

윈도우 기본 도구 "작업 스케줄러"를 검색해 엽니다.

2일차 Hooks가 "이벤트가 일어나면" 자동이었다면 — 작업 스케줄러는 "정해둔 시각이 되면" 자동입니다.

SETUP · 새 동작 만들기

"새 동작 만들기" — 세 칸을 이렇게 채운다

동작(I) 드롭다운은 "프로그램 시작" — 그 아래 세 칸을 화면 그대로 채웁니다.

① 프로그램/스크립트(P)
powershell
claude가 아니라 powershell — System32에 있어 이름만 적어도 윈도우가 찾습니다.
② 인수 추가(옵션)(A)
-NoExit -Command "claude -p '오후 5시까지 몇 분 남았는지 알려주고 log.txt에 한 줄 기록해줘'"
-NoExit = 실행 뒤 창이 안 닫힘. 바깥은 큰따옴표 ", claude 프롬프트는 작은따옴표 '. 프롬프트만 바꾸면 칭찬·주가 버전도 됩니다.
③ 시작 위치(옵션)(T)
c:\lecture\day3\headless
여기서 claude가 실행되고 — log.txt 기록도 이 폴더에 쌓입니다. 따옴표 없이 경로만.

세 칸을 다 채웠으면 — "확인"으로 저장. 막히는 부분이 있으면 화면을 캡처해 Claude에게 보여주며 물어보세요.

WOW · 5분마다

5분마다 — Claude가 말을 건다.

등록해 두면 5분마다 PowerShell 창이 떠 Claude가 답을 보여줍니다. -NoExit라 창이 안 닫혀 바로 읽고, log.txt엔 기록이 차곡차곡 쌓입니다.

창-NoExit — 결과가 눈앞에 그대로 남는다
기록headless 폴더의 log.txt 에 history
강의5시까지 5분마다 — 같이 카운트다운

SLASH · 또 하나의 내 명령

커스텀 슬래시 — 자주 하는 부탁을 한 단어로

왜 + 어디에

"방금 뭘 한 거야? 쉽게 정리해줘" — 같은 부탁을 매번 다시 칩니다. 한 번 적어 명령으로 굳히면 됩니다.

  • .md 파일 이름이 곧 명령 — asdf.md → /asdf
  • 개인 폴더 %USERPROFILE%\.claude\commands 에 두면 — 어떤 프로젝트에서나
  • 프로젝트 폴더의 .claude\commands 는 — 그 프로젝트 안에서만
%USERPROFILE%\.claude\commands\asdf.md
나는 비개발자라 잘 모르겠어.방금 한 대답을 — 딱 3줄로 요약.1줄: 방금 네가 뭘 했는지2줄: 지금 어떤 상태인지3줄: 내가 이제 뭘 하면 되는지# 이 파일이 곧 /asdf 명령

/asdf처럼 어디서나 쓸 명령은 — 개인 폴더에 한 번만 만들어 두면, 프로젝트에 상관없이 모든 곳에서 그대로 불러 씁니다.

INSIDE · 안에 적는 것

파일 안에는 — 평소 치던 부탁 그대로

본문

시킬 일을 사람 말로

평소 Claude에게 치던 그 문장 그대로. 어려운 용어 필요 없음 — "쉽게 정리해줘"면 충분.

또렷이

원하는 모습을 콕 집어

"딱 3줄로", "번호로", "내가 할 일만" — 답이 어떻게 나오면 좋을지 적어두면 매번 그렇게.

하나만

한 가지 일에 집중

슬래시 하나는 한 가지 일만 — 너무 많이 시키면 결과가 흐려짐.

형식이 헷갈리면 — "방금 한 일을 3줄로 정리해주는 슬래시 명령 만들어줘"라고 Claude에게 시키면 파일까지 만들어 줍니다.

CANDIDATES · 쓸모 있는 후보 6

비개발자가 만들면 좋은 — 슬래시 6가지

/asdf ★

방금 한 거, 내가 뭘 하면 되는지 딱 3줄로.

/easy

방금 설명을 — 더 쉬운 말로 다시.

/next

"그래서 지금 내가 뭘 하면 돼?"

/check

지금까지 한 거, 문제 없는지 점검.

/oops

에러가 났어 — 무슨 일이고 어떻게 풀지.

/save

지금까지 한 일을 깔끔하게 저장(커밋).

정답은 없습니다 — "내가 이번 주에 3번 이상 친 부탁"이 가장 좋은 후보. /asdf는 오늘 함께 만들어 봅니다.

CALL · 부르는 법

호출은 — / 치면 자동완성

쓰는 법

  1. / 를 치면 — 만든 명령이 목록에 뜸
  2. /asdf 선택 — 적어둔 부탁이 그대로 실행
  3. Claude가 길게 답한 직후에 치면 가장 유용

기본 슬래시(/model·/agents)와 같은 자리에 나란히.

파일을 만들면 — 다음부터 / 목록에 자동으로 나타납니다. 따로 등록할 필요 없음.

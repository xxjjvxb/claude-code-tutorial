CHAPTER 3 · SUBAGENT

서브에이전트 — 도우미 셋으로 메모장을 만든다

반복되는 역할을 떼어 전담시키는 도우미가 서브에이전트입니다. 오늘은 도우미 셋(화면·데이터·로그인)을 만들어 — 구글 로그인되는 "나만의 메모장" 앱을 직접 완성합니다. 데이터는 챕터 2의 Supabase에.

3도우미 에이전트
1나만의 메모장 앱
2빠른 완주자용 확장
WHY · 왜 나누나

한 대화에 모든 일을 시키면 — 점점 흐려진다.

메모장 하나를 만들어도 화면·데이터·로그인이 섞입니다. 한 대화에 다 시키면 맥락이 엉키죠. 역할을 떼어 전담 도우미에게 맡기는 게 서브에이전트입니다.

분리메인 대화는 깨끗하게 — 위임 작업은 따로
전문화역할마다 규칙을 따로 정한다
선택역할 난이도에 맞는 모델을 고른다
WHAT · 서브에이전트

서브에이전트 — 파일 하나가 도우미 하나

한 줄로

.claude/agents/ 폴더의 .md 파일 하나 = 도우미 하나. 그 안에 역할과 규칙을 적습니다.

  • 이 도우미가 무슨 일을 하는지
  • 지킬 규칙 — 어떻게 일해야 하는지
  • 어떤 모델을 쓸지 (선택)
.claude/agents/ui-helper.md
--- name: ui-helper--- model: sonnet너는 화면 담당이다. 단순하고깔끔한 메모장 화면을 만든다.기능은 적게, 보기 쉽게.

CLAUDE.md·슬래시를 써본 그 감각 그대로 — 사람 말로 역할을 적으면 도우미가 됩니다. /agents로 만듭니다.

CALL · 부르는 두 가지 방법

알아서 위임 — 또는 @로 지목

자동 위임

Claude가 알아서 부른다

  • 요청 내용이 어떤 도우미와 맞으면 — 알아서 위임
  • "메모장 화면 만들어줘" → 화면 도우미가 호출
  • 도우미 설명을 잘 적어둘수록 정확
@멘션 — 명시 호출

내가 직접 지목한다

  • @ui-helper 메모 입력칸 만들어줘
  • 어떤 도우미에게 맡길지 확실할 때
  • 1일차에 배운 @ 문법 그대로

처음엔 @멘션으로 명시 호출이 편합니다 — 누가 일했는지 눈에 보여서 감을 잡기 좋습니다.

MODEL · 역할에 맞는 모델

도우미마다 — 난이도에 맞는 모델

Haiku

가볍고 반복적인 일

정해진 형식의 정리·변환 — 빠르고 저렴.

Sonnet

일반적인 작업

화면 만들기·데이터 연결 — 대부분의 도우미에 무난한 기본값.

Opus

어렵고 깊은 일

구조 설계, 까다로운 디버깅 — 판단이 중요한 역할.

잘 모르겠으면 Sonnet으로 두세요 — 쓰다 보면 "이건 Haiku로 충분", "이건 Opus가 낫다"가 보입니다.

HOW · /agents 로 만든다

도우미는 — /agents로 만들고 관리

/agents 가 하는 일

  • 새 도우미 만들기 — 이름·역할·모델
  • 지금 있는 도우미 목록 보기
  • 역할 수정·삭제

.md 파일을 직접 안 건드려도 — 안내를 따라가면 됩니다.

claude · /agents
> /agents 1. 새 에이전트 만들기 2. 에이전트 목록# 안내대로 이름·역할 입력하면# .claude/agents/ 에 파일 생성

만든 도우미는 .claude/agents/ 폴더에 파일로 남습니다 — Git에 커밋하면 그대로 보관·공유됩니다.

EXTEND · 빠르게 끝났다면

메모장이 됐다면 — 두 걸음 더

STEP 1 · 찾기 좋게

메모가 쌓이면 — 찾는 게 일이 됩니다.

  • 검색칸 추가 — 단어로 메모 찾기
  • 태그·카테고리 — 메모를 분류
  • "오늘 쓴 메모만" 같은 필터

STEP 2 · 손에 익게

매일 쓰고 싶어지는 메모장으로.

  • 다크모드 · 색 테마 — 내 취향대로
  • 중요 메모 고정(pin) · 정렬
  • 완료한 메모에 체크 표시

정답 없음 — "내가 진짜 쓰고 싶은 기능"을 골라 도우미에게 시키세요. 더 떠오르면 그것도 좋습니다.

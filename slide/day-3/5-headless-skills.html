WHAT · 헤드리스

헤드리스 — 대화 없이 명령 한 줄로.

평소엔 Claude와 대화하지만, claude -p "..."는 대화창을 열지 않고 한 번의 요청을 즉시 처리하고 끝냅니다. 시연이 아니라 — 오늘은 각자 직접 써 봅니다.

한 줄요청 → 결과 → 종료. 대화 없음
자동화예약 작업 안에 끼워 — 사람 없이 실행
오늘직접 쳐 보고 — 자동 실행까지 건다
실습 · STEP 1 — 각자 직접

지금 바로 — claude -p 한 줄 쳐 보기

다 같이 한 번

  1. PowerShell을 연다
  2. claude -p 뒤에 따옴표로 부탁을 적는다
  3. 엔터 — 대화창 없이 결과만 바로 나온다

부탁만 바꿔 두세 번 더 — 손맛을 느껴 보세요.

PowerShell · headless
PS> claude -p "오늘 요일 알려주고 기분 좋아지는 한마디 해줘" 오늘은 수요일이에요. 절반을 넘었으니 — 잘 가고 있어요!# 대화창 없이 바로 끝

이게 헤드리스입니다 — 대화 없이 한 줄로. 다음은 이걸 "사람 없이 알아서 돌게" 만들어 봅니다.

AUTO · 작업 스케줄러

정해둔 시각에 — 알아서 실행

윈도우 작업 스케줄러

윈도우에 기본으로 있는 예약 실행 도구. "매일 아침 9시에 이 명령을 실행" 같은 약속을 걸어둡니다.

  • 실행할 것 — 내 claude -p 명령
  • 언제 — 매일·매시간 등 원하는 주기
  • 등록해 두면 — 컴퓨터가 알아서

무엇을 자동으로?

매번 손으로 하던 작은 일을 — 한 줄 명령으로 만들어 예약.

  • 관심 주제 소식을 정리해 파일로 저장
  • 오늘 일정·할 일을 아침에 정리
  • 환율·날씨 등 매일 챙기던 정보

등록이 헷갈리면 — Claude에게 "작업 스케줄러 등록 도와줘".

2일차 Hooks가 "이벤트가 일어나면" 자동이었다면 — 작업 스케줄러는 "정해둔 시각이 되면" 자동입니다.

WOW · 자동 아침 비서

자고 일어나면 — 결과가 와 있다.

"매일 아침 7시, 내 관심 주제를 요약해 파일로 저장." 한 번 걸어두면 — 내가 아무것도 안 해도 매일 아침 정리된 파일이 기다립니다. 이게 헤드리스의 진짜 맛입니다.

한 번claude -p 명령 + 스케줄러 등록
매일사람 없이 — 알아서 실행된다
느낌"내가 안 시켰는데 Claude가 일했네"
실습 · 헤드리스

직접 → 자동 → 메모장까지

1

claude -p 직접 쳐 보기 — 부탁을 바꿔 두세 번 (전원 한 번씩)

2

자동 실행할 명령 정하기 — "관심 주제 요약을 파일로 저장"

3

작업 스케줄러에 등록 — Claude 안내대로, 매일/매시간 자동 실행

★

확장 — 메모장에 넣기 — 파일 대신 챕터 3 메모장(Supabase)에 자동 입력

먼저 1~3으로 "파일에 저장"을 끝내면 전원 성공. ★는 빠른 분의 확장 — 내 메모장이 알아서 채워집니다.

WOW · 진짜 파일이 나온다

코드 한 줄 없이 — 진짜 PPT·엑셀이 툭.

한 줄 요청 → 더블클릭하면 PowerPoint·Excel에서 그대로 열리는 진짜 파일. 특히 수식·표가 들어간 엑셀은 — "이거 그냥 회사에서 쓰는 파일이잖아" 소리가 나옵니다.

입력"이 내용을 발표 자료로" 한 줄
출력.pptx · .xlsx — 진짜 열리는 파일
느낌"내가 코드를 안 썼는데 — 됐다"

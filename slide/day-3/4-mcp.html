CHAPTER 4 · MCP

MCP — 외부 세계와 연결하고, 크롤링까지

Claude는 기본적으로 내 프로젝트 폴더 안만 봅니다. MCP는 파일·GitHub·브라우저 같은 외부 도구를 꽂는 "표준 포트"입니다. 연결을 배우고 — 끝으로 브라우저 MCP로 웹 정보를 직접 긁어옵니다.

WHY · 왜 필요한가

Claude 혼자선 — 담장 안만 본다.

Claude Code는 지금 열어둔 프로젝트 폴더를 다룹니다. 그 밖의 파일, GitHub 이슈, 인터넷 페이지는 — 연결해 주기 전엔 닿지 못합니다.

기본열어둔 폴더 + 터미널까지
한계외부 서비스·웹 페이지는 못 봄
MCP그 바깥 도구를 Claude에 연결해 준다
WHAT · MCP가 뭔가

MCP — 외부 도구를 꽂는 USB 포트.

예전엔 기기마다 다른 케이블이 필요했지만 USB 하나로 통일됐듯 — MCP는 "외부 도구를 AI에 연결하는 공통 규격"입니다. 한 방식만 알면 어떤 도구든 꽂을 수 있습니다.

규격도구마다 다른 방식 X — 하나의 표준
교체필요한 도구만 꽂고 — 안 쓰면 뺀다
내가 할 일"연결" 한 줄 — 쓰는 법은 Claude가
HOW · 연결은 한 줄

연결 — claude mcp add 한 줄

이렇게 합니다

  • 터미널에 claude mcp add + 도구 이름
  • 한 번 연결하면 — 그 프로젝트에서 계속 사용
  • 연결 상태는 claude mcp list로 확인

설정이 헷갈리면 — "브라우저 MCP 연결 도와줘" 한 줄.

PowerShell · MCP 연결
PS> claude mcp add playwright ✓ playwright 연결됨PS> claude mcp list playwright · 연결됨

정확한 명령은 도구마다 조금씩 다릅니다 — Claude에게 "이 MCP 연결 명령 알려줘"라고 물어 받는 게 가장 확실합니다.

SAFETY · 권한 감각

읽기는 마음껏 — 쓰기·삭제는 한 번 멈춰서.

MCP는 외부 도구에 손을 댑니다. 읽어 오는 일은 거의 안전하지만, 파일을 바꾸거나 지우는 일은 — 1일차에 배운 권한 감각 그대로 신중하게.

읽기참고·조회·수집 — 부담 없이
쓰기수정·삭제 — 권한 prompt를 꼭 읽고
범위필요한 폴더·사이트만 다룬다
COMPARE · 헷갈리지 않게

서브에이전트는 사람, MCP는 도구

서브에이전트

역할을 맡는 도우미

  • 여전히 Claude — 역할·규칙만 따로
  • "누가 일하나"를 나눈다
  • 예: 화면 도우미, 데이터 도우미
MCP

외부와 잇는 연결

  • Claude가 아님 — 도구로 가는 통로
  • "무엇에 닿을 수 있나"를 넓힌다
  • 예: 브라우저, 파일, GitHub

둘은 함께 쓰입니다 — 도우미(에이전트)가 도구(MCP)를 들고 일하는 그림. 이제 브라우저 도구를 꽂아 봅니다.

PROJECT · 와 이게 되네

Claude가 — 직접 웹을 돌아다닌다.

브라우저 MCP를 꽂으면, Claude가 진짜 브라우저를 열어 페이지를 보고·넘기고·정보를 긁어옵니다. 흩어진 웹 정보를 한 번에 모아오는 — "크롤링"입니다.

연결브라우저 MCP를 한 줄로 꽂는다
시킴"이 정보 모아줘" — 사람 말로
결과흩어진 정보가 — 표 하나로
TOOL · 브라우저 MCP

브라우저 MCP — Claude가 진짜 브라우저를 연다

무엇을 하나

  • 실제 브라우저 창을 열어 페이지를 본다
  • 스크롤·클릭·다음 페이지로 넘기기
  • 화면의 정보를 읽어 와 정리

대표 도구는 Playwright — 연결은 Claude에게 물어보면 됩니다.

가볍게 — 규칙은 지키며

  • 공개된 정보를, 가벼운 양만 — 부담 없이
  • 로그인 담벼락 안쪽·대량 수집은 피하기
  • 사이트 이용 규칙을 존중

오늘은 "이게 되네"를 느끼는 게 목적 — 작게.

크롤링이 막히는 사이트도 있습니다 — 안 되면 다른 사이트로. "이 사이트에서 막혀"라고 하면 Claude가 대안을 찾아줍니다.

여러 페이지의 화면을 한 번에 캡처.

정답 없음 — "내가 평소 손으로 찾아보던 것"이 가장 좋은 소재입니다. 그걸 Claude가 대신 모아옵니다.

실습 · 진행

브라우저 MCP — 크롤링 한 바퀴

1

브라우저 MCP 연결 — Claude에게 "브라우저 MCP 연결 명령 알려줘"

2

소재 하나 정하기 — 가격·뉴스·후기 등 평소 찾아보던 것

3

모아 달라고 시키기 — "이 정보를 모아서 표로 정리해줘"

4

결과 확인 + 다듬기 — "정렬해줘" "이 항목도 추가" — 마음에 들 때까지

막히면 다른 사이트로 — 크롤링은 사이트마다 사정이 다릅니다. 핵심은 "Claude가 웹을 직접 다닌다"는 감각.

WRAP · MCP 끝

필요한 도구를 — 한 줄로 꽂는다

MCP는 Claude의 손이 닿는 범위를 넓히는 표준 포트입니다. 브라우저를 꽂으니 — Claude가 웹을 직접 돌아다녔습니다.

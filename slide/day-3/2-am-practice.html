STEP 01 · git clone

오픈 텍스트 게임 받아오기

단계

  1. 바탕화면에 새 폴더 Day3 생성
  2. 해당 폴더 우클릭 → "터미널에서 열기"
  3. git clone <강사 제공 URL>
  4. cd로 받은 폴더로 진입
  5. VS Code에서 폴더 열고 claude
PowerShell — Day3/
PS> git clone https://github.com/.../text-adventure Cloning into 'text-adventure'... ✓ 12 files receivedPS> cd text-adventurePS> ls game.py · rooms.json · README.md ...

URL은 단톡방에 공유. clone 끝나면 일단 python game.py로 한 번 돌려보세요 — 동작 확인.

STEP 01b · Plan 모드 분석

Plan으로 분석만 시키기

claude · plan · text-adventure/
# Shift+Tab 두 번 → plan 모드 [plan]> @. 이 게임의 구조 분석해줘. 코드는 아직 수정 X. 분석 결과: · game.py — 메인 루프 (방 이동 + 명령 파싱) · rooms.json — 방 데이터 (이름·설명·연결) · player.py — 플레이어 상태 (위치·인벤토리) · 체력 시스템 X · 전투 X · 시간 제한 X → 확장 가능 포인트: 체력·전투·시간·레벨 등

Plan 모드 + "수정 X"라고 명시해서 읽기만 하게 만듭니다 — 실수로 파일 변경되는 일 방지.

STEP 02 · 체력 시스템 추가

Plan으로 계획 → 승인 → 실행

claude · plan · 체력 시스템
> player에 체력 시스템 추가. 시작 100 · 위험 방 진입 시 -10 · 0이면 게임오버 계획서: 1. player.py — health 속성 추가 (default 100) 2. rooms.json — danger 필드 추가 (true/false) 3. game.py — 방 진입 시 danger면 health -= 10 4. game.py — health 0이면 game over 메시지 + exit → 3개 파일 수정 (기존 흐름 유지) [Approve / Edit / Reject]> approve ✓ player.py 수정 ✓ rooms.json 수정 ✓ game.py 수정

실행 후 python game.py로 한 번 돌려보고 → git commit -am "체력 시스템 추가". commit 빠뜨리지 않기.

STEP 03a · Telegram 가입

휴대폰에 Telegram 앱 설치

1

App Store / Play Store에서 Telegram 검색 → 설치

2

앱 실행 → 본인 휴대폰 번호로 가입 (SMS 인증)

3

이름·아이디 설정 → 가입 완료

4

앱 안에서 검색 (돋보기) → BotFather 검색 → "+ Start" 누르기

계정 만들기 한 번만 — 5분 안에 끝납니다. 이미 Telegram 쓰던 분은 4번부터.

STEP 03b · BotFather로 봇 생성

/newbot — 토큰 발급

BotFather 대화

  1. /newbot 입력
  2. 봇 이름 (예: Claude Notify)
  3. 봇 username (영문, 끝이 bot)
  4. 토큰 받음 → 복사해서 메모장에
Telegram · BotFather
/newbot Choose a name for your bot.Claude Notify Now choose a username...claude_notify_2026_bot Done! Use this token: 7891234567:AAH...xyz# ↑ 토큰 — 절대 공유 X

토큰 = 비밀번호와 같음. 단톡방·코드에 직접 적지 마세요. 메모장에 임시 저장 → 환경변수로 사용.

STEP 03c · chat_id 확보

본인 봇과 첫 대화 → chat_id 받기

단계

  1. BotFather 메시지에서 봇 링크 클릭 → 본인 봇 화면
  2. "+ Start" 버튼 → "안녕" 한 번 보내기
  3. 브라우저로 api.telegram.org/bot<TOKEN>/getUpdates
  4. JSON에서 "chat":{"id":...} 숫자 복사
getUpdates JSON
{ "ok": true, "result": [{ "message": { "chat": { "id": 123456789, ... }, "text": "안녕" } }]}# 이 숫자 (123456789) = chat_id

봇과 한 번이라도 대화해야 getUpdates에 chat이 나타납니다 — "안녕" 안 보내면 빈 결과.

STEP 03d · settings.json 작성

.claude/settings.json — Stop 훅 추가

.claude/settings.json
{ "hooks": { "Stop": [{ "matcher": "", "hooks": [{ "type": "command", "command": "curl.exe -s -X POST https://api.telegram.org/bot<TOKEN>/sendMessage -d chat_id=<CHAT_ID> -d text='✓ Claude 응답 끝'" }] }] }}

<TOKEN>과 <CHAT_ID>를 본인 값으로 교체. curl.exe(점exe 필수) — PowerShell의 가짜 curl 피하기.

STEP 03e · 동작 확인

짧은 명령 → 휴대폰 알림 확인

claude · 알림 테스트
# 1) Claude 재시작 (settings.json 갱신을 위해)> /exitPS> claude# 2) 짧은 응답 시키기> "안녕" 이라고 한 번 답해줘 안녕! [Stop hook fired] ✓ Telegram에 메시지 전송# 3) 휴대폰 → Telegram → 본인 봇 채팅# "✓ Claude 응답 끝" 표시 보임

알림 안 오면: ① TOKEN 오타 ② chat_id 오타 ③ curl이 아닌 curl.exe ④ Claude 재시작 안 함 — 이 4가지 우선 점검.

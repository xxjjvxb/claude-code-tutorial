왜 그 폴더에서?

스킬은 — 지금 Claude가 켜진 폴더의 파일을 가지고 일합니다. 1일차 자기소개 index.html이 있는 폴더에서 시작해야 그 파일을 PPT로 바꿀 수 있습니다.

  • 1일차에 index.html을 만든 폴더를 연다
  • 그 폴더 안에서 claude 실행
  • 새 폴더 말고 — 꼭 그 폴더에서
PowerShell · 1일차 폴더
# 1일차 자기소개를 만든 폴더로 이동PS> cd c:\lecture\day1# index.html 이 보이면 — 제대로 왔다PS> dir index.html style.cssPS> claude

폴더 위치가 기억 안 나면 — 1일차에 자기소개를 저장한 곳입니다. 탐색기에서 찾아 주소창의 경로를 복사해 cd 뒤에 붙여넣으면 됩니다.

INSTALL · 스킬 설치

스킬 설치 — 두 줄이면 끝

마켓플레이스에서 한 번에

공식 문서 스킬은 "마켓플레이스"에서 받습니다. document-skills 묶음 하나에 — PPTX·PDF·DOCX·XLSX가 다 들어 있습니다.

  1. 보관소 등록 — /plugin marketplace add
  2. 설치 — /plugin install document-skills
  3. 적용 — /reload-plugins (또는 claude 재시작)
  4. 메뉴가 뜨면 — 화살표로 골라 "Install" 해도 OK
claude · /plugin
> /plugin marketplace add anthropics/skills ✓ anthropic-agent-skills 등록> /plugin install document-skills@anthropic-agent-skills ✓ pptx · pdf · docx · xlsx 설치 완료> /reload-plugins ✓ 플러그인 다시 불러옴 — 즉시 사용 가능# 이후엔 — 필요할 때 Claude가 알아서 켠다

document-skills 한 번 설치로 PPTX·PDF 둘 다 준비 끝. 설치 직후엔 /reload-plugins를 한 번 — 안 그러면 다음 claude 재시작까지 활성화가 안 됩니다. 명령이 헷갈리면 — Claude에게 "공식 문서 스킬 설치를 도와줘"라고 하면 이 과정을 대신 안내합니다.

MAKE · 자기소개 → PPT

자기소개를 — 진짜 PPT로

이렇게 시킵니다

스킬을 따로 부르지 않아도 됩니다 — "발표 자료로 만들어줘"라고만 하면 Claude가 알아서 pptx 스킬을 켭니다.

  • index.html을 가리키며 — "발표용 PPT로"
  • 표지·본문이 갖춰진 .pptx가 생성
  • 아쉬우면 — "글자 크게"처럼 한 줄로 다듬기
claude · day1
> index.html 내용으로 발표용 PPT를 만들어줘. 표지 1장 + 본문으로. ✓ pptx 스킬 실행 ✓ 자기소개.pptx 생성> 제목 글자를 더 크게 해줘 ✓ 자기소개.pptx 수정> 이 자기소개를 PDF로도 만들어줘

PDF도 똑같이 — "이 자기소개를 PDF로도". 만든 .pptx는 더블클릭하면 PowerPoint에서 바로 열립니다. 한 번에 완벽하지 않아도 — 한 줄씩 고치면 됩니다.

WOW · 진짜 파일이 나온다

코드 한 줄 없이 — 진짜 PPT·PDF가 툭.

"내 자기소개를 발표 자료로" 한 줄 → 더블클릭하면 PowerPoint에서 그대로 열리는 진짜 .pptx. PDF도 같은 방식. 코드를 한 줄도 안 썼는데 — 업무에 바로 쓰는 파일이 나옵니다.

입력"내 자기소개를 발표 자료로" 한 줄
출력.pptx · .pdf — 진짜 열리는 파일
느낌"코드를 안 썼는데 — 됐다"
DESIGN.md · designmd.ai

디자인을 — 파일 하나로 통째로.

designmd.ai에 가면 — 색·글꼴·간격 같은 "디자인 규칙"을 DESIGN.md 마크다운 파일 하나로 모아둔 걸 무료로 받을 수 있습니다. 이 파일을 Claude가 읽으면 — 결과물이 그 디자인대로 통일됩니다.

CONSISTENCY · 통일성

웹·PPT·PDF 한 세트

Claude가 같은 DESIGN.md를 기준 삼아 — 자기소개 페이지도, PPT도, PDF도 같은 톤으로.

바꾸기 쉽게

한 번 고치면 전부

테마를 바꾸고 싶으면 DESIGN.md만 — 결과물 전체가 새 테마로 따라옵니다.

DESIGN.md는 본래 웹 화면용 디자인 명세지만 — Claude가 이를 기준으로 PPT·PDF에도 같은 색·글꼴을 입혀, 흩어진 결과물이 "한 브랜드"처럼 보이게 됩니다. 이게 템플릿 통일성입니다.

실습 · 한 바퀴

자기소개를 — PPT·PDF + 새 테마로

1

1일차 폴더에서 claude 실행 — index.html이 있는 그 폴더에서

2

문서 스킬 설치 — /plugin으로 document-skills (PPTX·PDF 한 묶음)

3

자기소개 → PPT·PDF — "발표용 PPT로", 이어서 "PDF로도"

4

DESIGN.md 받기 — designmd.ai에서 골라 받아 작업 폴더에 두기

5

통일된 테마로 — "@DESIGN.md로 자기소개를 다시 꾸며줘"

막히면 — 화면을 캡처해 Claude에게 보여주거나, 에러를 그대로 붙여넣기. 한 줄씩 다듬으면 마음에 드는 결과가 나옵니다.

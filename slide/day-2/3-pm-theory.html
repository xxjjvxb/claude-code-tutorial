MODE SWITCH · Shift+Tab

모드 사이를 Shift+Tab으로 순환

단축키 한 가지

claude 입력란에서 Shift + Tab 누를 때마다 모드 순환:

  • Interactive → Auto → Plan → 다시 Interactive
  • 현재 모드는 입력란 상단에 표시

--dangerously-skip-permissions는 강의 중 한 번도 쓸 일 없음. 호기심에라도 X.

TOPIC 02 · PERMISSIONS

권한 prompt — 한 줄은 읽고 승인

언제 prompt가 뜨나

  • 파일 쓰기·삭제 — 내용 변경
  • 셸 명령 — git, npm, curl 등
  • 네트워크 — 외부 API · 다운로드
  • 새 의존성 — npm install 등

3가지 옵션

  • Allow once — 이번 한 번만 (권장 default)
  • Always allow — 이 명령은 앞으로 자동
  • Deny — 거절

새 명령은 Allow once로 시작 — 신뢰 쌓이면 always로. 처음부터 always는 사고의 시작.

RULE · 1줄로 끝

"always allow 무지성 금지"

이 한 줄이 5일 내내 사고를 막는다. always allow는 그 명령을 다음부턴 묻지 않겠다는 약속 — 어떤 명령에 약속할지 신중히.

OKgit status · ls · cat — 읽기만 하는 명령
주의git add · git commit — 변경은 가능
절대 Xrm -rf · git push --force · npm publish

TOPIC 04 · CONTEXT · 컨텍스트 관리

대화가 길어지면 매 응답이 비싸진다.

컨텍스트 = 지금까지의 대화 + 첨부된 파일 + CLAUDE.md. 매 요청마다 이 모두가 다시 입력 토큰으로 계산됩니다 — 길수록 비용 ↑.

시작10K 토큰 — 한 요청 $0.03
1시간 후80K 토큰 — 한 요청 $0.24
대응주제 끝나면 /clear 또는 /compact
CONTEXT TOOLS · /clear vs /compact

컨텍스트 줄이기 두 가지 방식

/clear · 통째로 비우기

새 세션처럼 — 가장 가벼움

  • 이전 대화를 전부 컨텍스트에서 빼냄
  • 다음 요청부터 토큰 0부터
  • 주의: Claude가 이전 대화를 더 이상 기억 못 함
  • CLAUDE.md는 자동 다시 주입
/compact · 요약해서 유지

대화 흐름은 살리고 토큰만 ↓

  • 지금까지 대화를 Claude가 자동 요약
  • 요약된 형태로 컨텍스트에 유지
  • 주제 이어서 작업 가능
  • "방금 본 것"은 잊을 수 있음

주제가 완전히 바뀌면 /clear, 같은 주제로 더 가야 하면 /compact.

CONTEXT TOOLS · /resume vs --continue

세션 종료 후 이어가기 두 가지

/resume · 세션 안에서 선택

claude를 이미 켰을 때

  • 같은 폴더에서 claude 실행
  • 세션 안에서 /resume 입력
  • 이전 세션 목록 → 선택해서 복원
  • 여러 세션 중 선택 가능
--continue · 셸 옵션으로 바로

claude 실행 시 즉시 복귀

  • PowerShell에서 claude --continue
  • 직전 세션 자동 복원 — 가장 빠름
  • 가장 흔한 사용 — 끄고 다시 켰을 때
  • 여러 세션 중 선택은 X (직전만)

하루 종일 작업하다 노트북 잠겼을 때 — claude --continue 한 줄로 어제 멈춘 자리 그대로.

RECAP · 컨텍스트 4 도구

상황별 선택 가이드

/clear

주제 바뀜

아예 다른 작업으로 넘어갈 때. 컨텍스트 0부터.

/compact

길어졌지만 이어가야

같은 주제로 더 가야 하는데 토큰 부담될 때.

/resume

세션 선택 복원

claude 켜놓고 여러 이전 세션 중 골라서 복원.

--continue

직전 이어가기

claude 실행 옵션. 직전 세션 즉시 복원 — 가장 흔함.

처음엔 /clear와 --continue 두 개만 손에 익히면 충분 — /compact, /resume은 필요할 때 추가.

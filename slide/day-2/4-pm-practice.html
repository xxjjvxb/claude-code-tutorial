MISSION 1 · 가위바위보 CLI

왜 3단계로 쪼개는가

× 한 번에 시키기
"가위바위보 CLI 만들어줘 · 5판 기록 + 통계도"
...
토큰 30K · 코드 200줄 통째로
어디 잘못됐는지 검증 어려움

큰 prompt = 검증 불가 + 디버깅 막힘.

✓ 3단계로 — 오늘의 방식
1) 뼈대만 — 15분 + 검증 + commit
2) 사용자 입력 추가 — 15분 + 검증
3) 기록 5판 추가 — 15분 + 검증
각 단계 끝마다 동작 확인 가능

단계마다 git commit — 망쳐도 직전 단계로 복귀 가능.

MISSION 1 · STEP 1 · 뼈대

먼저 동작하는 골격만

시키는 말

  • "가위바위보 CLI를 Python으로"
  • "뼈대만 먼저 — 컴퓨터 손이 랜덤 + 결과 출력"
  • "한 판만 — 사용자 입력은 다음에"
  • "game.py 한 파일"
PowerShell — 검증
PS> python game.py 컴퓨터: 바위 결과: (테스트용 출력)# 동작하면 → 커밋PS> git add .PS> git commit -m "가위바위보 뼈대"

한 단계 끝 = 검증 + commit. 동작 확인 안 되면 다음 단계로 가지 마세요.

MISSION 1 · STEP 2 · 사용자 입력

이제 사용자가 한 손을 넣는다

시키는 말

  • "@game.py에 사용자 입력 추가"
  • "가위/바위/보 중 하나 입력받기"
  • "이상한 입력은 다시 묻기"
  • "승/무/패 메시지 한국어로"
실행 — 한 판
PS> python game.py 가위/바위/보 중 하나 입력: 바위 컴퓨터: 가위 결과: 이김 🎉# 정상 동작 → 커밋PS> git commit -am "사용자 입력 추가"

@game.py 멘션을 쓰면 Claude가 현재 코드를 보고 추가합니다 — 처음부터 다시 짜는 게 아님.

MISSION 1 · STEP 3 · 5판 + 기록

마지막 — 5판 + 결과 누적

MISSION 2 · 단위 변환기

  • cm ↔ inch 변환
  • kg ↔ lb 변환

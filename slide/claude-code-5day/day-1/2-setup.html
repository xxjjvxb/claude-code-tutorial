STEP 01 (1/2) · VS Code 설치

VS Code · Microsoft Store로 설치공식 사이트에서 설치

받는 곳
Microsoft Store → "Visual Studio Code"
  1. Windows 키를 눌러 시작 메뉴 검색 → store 입력 → 결과에 뜨는 "Microsoft Store" 앱 실행
  2. 검색창에 Visual Studio Code → 첫 번째 결과 (Microsoft Corporation) 클릭
  3. "받기"(Get/Install) 클릭 → 자동 다운로드 + 설치 (약 30초~1분)
  4. 완료 후 "열기" 또는 시작 메뉴에서 "Visual Studio Code" 실행
  5. (선택) Extensions → "Korean" 검색 → 언어팩 설치하면 한국어 메뉴
받는 곳
code.visualstudio.com → "Download for Mac"
  1. code.visualstudio.com 접속 → 가운데 "Download for Mac" 버튼 (Apple Silicon / Intel 자동 감지)
  2. 다운로드된 VSCode-darwin-*.zip 더블클릭 → 자동 압축 풀림 → "Visual Studio Code.app" 생성
  3. 응용 프로그램(Applications) 폴더로 드래그해 이동 — Launchpad에서 검색 가능해짐
  4. 첫 실행 시 Gatekeeper 경고 → "열기" 클릭 (App Store 외부 앱 1회 승인)
  5. (선택) Extensions → "Korean" 검색 → 언어팩 설치하면 한국어 메뉴

STEP 02 · CONCEPT · 환경변수 · PATH

환경변수 — 시스템이 공유하는 설정값

PATH가 뭔가

"명령어를 어디서 찾을지" 폴더 목록을 적어둔 환경변수.

  • PowerShell셸(zsh)이 claude를 PATH 폴더들에서 검색
  • 설치 스크립트가 PATH에 자동 추가
  • 새로 등록된 PATH는 새 PowerShell터미널 창에서만 적용
PATH (시스템 환경변수) ├── C:\Windows\System32 ├── C:\Users\you\.claude\bin\ ← claude.cmd └── ... PS> claude → 위 폴더들에서 검색 → 실행
$PATH (환경변수) ├── /usr/local/bin ├── /usr/bin ├── ~/.claude/bin/ ← claude └── ... $ claude → 위 폴더들에서 검색 → 실행

"인식되지 않습니다command not found"는 99% PATH 문제. 새 PowerShell터미널 창이 1차 해결책.

STEP 03 · Claude Code 설치

설치 방법 3가지 — 본인 환경에 맞게

방법 1 · PowerShell 한 줄 — 이번 강의 메인
PS> irm https://claude.ai/install.ps1 | iex
irm(다운로드) | iex(실행). Node.js 없이 한 줄로 끝.
방법 2 · cmd 한 줄
> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
PowerShell 정책이 막혀 있을 때 대안.
방법 3 · npm 전역 (Node.js 이미 있을 때)
PS> npm install -g @anthropic-ai/claude-code
npm update로 업데이트도 한 줄.
방법 1 · 터미널 한 줄 — 이번 강의 메인
$ curl -fsSL https://claude.ai/install.sh | bash
다운로드 후 즉시 실행. Node.js 없이 한 줄로 끝.
방법 2 · Homebrew (이미 brew 쓰는 분)
$ brew install anthropic/tap/claude-code
설치·업데이트를 brew upgrade 한 줄로.
방법 3 · npm 전역 (Node.js 이미 있을 때)
$ npm install -g @anthropic-ai/claude-code
npm update로 업데이트도 한 줄.

설치 직후 PowerShell터미널을 껐다 새로 열어야 PATH 갱신 → claude 인식. 실패 시 → 관리자 권한 PowerShell.실패 시 → sudo 또는 권한 확인.

선택 A · Node.js · 나중에 프론트엔드 만들 때

Node.js — 필요할 때 설치

받는 곳
https://nodejs.org
  1. nodejs.org 접속 → "LTS" 큰 버튼 클릭 (Windows .msi 자동 다운로드)
  2. node-v20.x.x-x64.msi 더블클릭 → 보안 경고 "예" → 설치 마법사 Next 따라 진행
  3. Custom Setup에서 "Add to PATH" 체크 확인 → Install → UAC 승인 → 1~2분 대기
  4. 완료 후 새 PowerShell에서 node --version → v20.x.x 출력되면 OK
받는 곳
Homebrew · nodejs.org
  1. Homebrew가 설치돼 있으면 brew install node 한 줄 — 30초~1분
  2. Brew가 없으면 nodejs.org → "LTS" 버튼 → .pkg 다운로드 → 더블클릭 → 설치 마법사
  3. 설치 후 새 터미널에서 node --version → v20.x.x 출력되면 OK
  4. Homebrew 자체 설치는 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

오늘 Claude Code 사용에는 필요 없습니다. Node.js는 나중에 프론트엔드(React·Vue) 또는 npm 패키지 도구 만들 때만.

선택 B · TROUBLESHOOTING · 자주 막히는 5가지

막혔을 때 먼저 시도할 것들

01
"인식되지 않습니다command not found"
새 PowerShell터미널 창 → PATH 갱신. 안 되면 시작 메뉴Spotlight에서 다시 검색해 실행.
02
PowerShell 스크립트 실행 정책 에러
관리자 PowerShell → Set-ExecutionPolicy -Scope CurrentUser RemoteSigned → 재시도.
02
"Permission denied" / 실행 권한 에러
설치 스크립트를 다시 실행하거나, 막힌 파일에 chmod +x ~/.claude/bin/claude. Mac은 별도 정책 없음 — 권한만 맞으면 OK.
03
claude 실행 시 결제·인증 에러
팀 초대 메일을 받아 수락했는지 확인. 안 왔으면 강사에게 메일 주소 등록 요청.
04
로그인 브라우저가 안 열림
터미널에 표시되는 URL을 직접 복사해서 브라우저에 붙여넣기.
05
VS Code에서 code 명령이 인식 안 됨
VS Code → Ctrl⌘+Shift+P → "Install 'code' command in PATH" → 새 PowerShell터미널 재시도.

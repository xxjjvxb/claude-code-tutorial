TOOLS · 두 도구

PySide로 창을 그리고, PyInstaller로 굳힌다

PySide6 — 창을 그린다

파이썬으로 창·버튼·입력칸을 그리는 도구. Qt라는 유명한 GUI 도구의 파이썬 버전.

  • "이 버튼을 누르면 ~" 만 짜면 됨
  • 코드는 Claude가 — 우리는 무엇을 만들지만
  • 운영체제 그대로의 모양 — 윈도우다움

PyInstaller — .exe로 굳힌다

파이썬으로 만든 .py 파일을 .exe 한 덩어리로 묶어줍니다. 파이썬이 없는 PC에서도 그대로 동작.

  • 명령 한 줄 — pyinstaller --onefile
  • 1~2분이면 .exe 완성
  • 파일 하나로 친구한테 보내기

둘 다 명령 한 줄로 설치. 코드는 Claude가 씁니다 — 우리는 무엇을, 어떻게 동작할지만 말합니다.

SETUP · 준비물

두 도구 설치 — 한 줄이면 끝

Python 3.12 — 이미 깔려 있다

Day 1에 깐 Python 3.12를 그대로 씁니다. 새 PowerShell 창에서 python --version — 3.12.x가 뜨면 OK.

  • 안 뜨면 — Day 1 셋업 슬라이드의 PATH 점검
  • pip는 파이썬과 함께 — 따로 설치 불필요
  • PySide6·PyInstaller 둘 다 3.12 정식 지원
PowerShell · 한 줄 설치
PS> python --version Python 3.12.xPS> pip install pyside6 pyinstaller ... (다운로드 1~3분) Successfully installed PySide6 pyinstaller# 한 번만 — 다음부터는 바로 사용

PySide6는 다운로드가 좀 큽니다(수십 MB) — 와이파이가 약하면 3~5분. pip는 인터넷에서 도구를 받아오는 명령입니다.

BUILD · .exe로 굳히기

PyInstaller — 한 줄로 .exe 완성

명령 한 줄

pyinstaller --onefile myapp.py — 진행 메시지가 쏟아져도 가만히 1~2분.

  • 결과는 dist\myapp.exe 하나
  • 다른 PC에 옮겨도 동작 — 파이썬 없어도
  • --onefile = 한 덩어리, --onedir = 폴더로 분산(더 빠른 실행)
PowerShell · 빌드
PS> pyinstaller --onefile myapp.py INFO: PyInstaller: 6.x ... (1~2분) INFO: Building EXE ... completed INFO: Building dist\myapp.exePS> .\dist\myapp.exe# 더블클릭과 동일 — 창이 뜬다

옵션을 외울 필요 없습니다 — "이 .py를 .exe 한 덩어리로 만들어줘"라고 Claude에게 부탁하면 명령까지 대신 칩니다.

TROUBLE · 막힐 때 체크

자주 걸리는 — 5가지 + 해법

01
"pyside6를 찾을 수 없다"
pip 설치가 안 됐거나 다른 파이썬을 쓰는 중. pip install pyside6를 그 PowerShell 창에서 한 번 더.
02
.py가 안 뜬다 — 까만 창만 깜빡
에러 메시지가 잠깐 뜨고 닫힘. python myapp.py를 PowerShell에서 직접 실행하면 메시지가 남음 → 그대로 Claude에게.
03
PyInstaller 빌드 에러
출력 끝부분의 빨간 줄을 통째로 복사해 Claude에게. 대개는 "이 라이브러리도 같이 묶어줘" 한 줄 추가로 해결.
04
.exe 더블클릭했더니 "Windows의 PC 보호"
정상. "추가 정보 → 실행". 슬라이드 13 참고.
05
.exe가 백신에 격리됐다
서명 없는 새 파일이라 가끔 오탐. Windows 보안 → 보호 기록 → 복원. 작업 폴더를 Defender 예외에 추가해두면 재발 방지.

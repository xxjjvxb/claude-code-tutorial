STEP 02a · MCP Filesystem 추가

한 줄 — claude mcp add

PowerShell — MCP 등록
# 1) claude 종료 (밖에서 등록해야 함)> /exit# 2) PowerShell에서 한 줄 — 현재 폴더 마운트PS> claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem . ✓ filesystem 서버 등록# 3) 확인PS> claude mcp list · filesystem (npx -y @modelcontextprotocol/server-filesystem .)# 4) Claude 다시 시작 → 자동 연결PS> claude

처음 실행 시 npx가 패키지 다운로드 — 1~2분 걸릴 수 있음. 정상 표시: ✓ filesystem connected.

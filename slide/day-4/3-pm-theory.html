TRACK 1 · 커스텀 슬래시

자주 쓰는 프롬프트를
한 줄 명령으로.

"이 프로젝트에 매번 똑같이 시키는 프롬프트"가 있으면 슬래시로 — /mycommand 한 번이면 끝.

위치.claude/commands/<name>.md — 마크다운 1 파일
호출/<name> — Claude가 자동 인식
인자$ARGUMENTS 변수로 입력 받기 가능
DEFINITION · .md 파일

파일 형식 — CLAUDE.md와 비슷

.claude/commands/review.md
---description: 코드 리뷰 — 보안·성능·가독성 순으로 평가---# 코드 리뷰 요청현재 변경사항 (또는 명시된 파일)을 다음 순서로 검토:1. **보안** — SQL injection · XSS · 시크릿 노출 등2. **성능** — 불필요한 루프 · DB 쿼리 N+1 등3. **가독성** — 변수명 · 함수 길이 · 주석 부재각 항목별로 1~3줄 코멘트 + 구체적 라인 번호 제시.$ARGUMENTS 가 있으면 그 파일·범위에 한정.

호출 시: /review src/auth.py → $ARGUMENTS가 src/auth.py로 치환됨.

CANDIDATES · 좋은 슬래시 후보

본인 미니에 어떤 걸 — 5가지 추천

/review

현재 변경사항 코드 리뷰 — 보안·성능·가독성.

/refactor

$ARGUMENTS 파일을 더 읽기 쉽게 정리.

/explain

$ARGUMENTS 함수가 뭘 하는지 한국어로 설명.

/commit-msg

git status 확인 후 commit 메시지 한 줄 제안.

/changelog

최근 commit들 요약해서 CHANGELOG.md 한 항목.

실습에서 1개 ★

위 5개 중 하나 골라 만들거나, 본인 자주 쓰는 프롬프트로.

"본인이 매주 5번 이상 시키는 프롬프트"가 가장 좋은 슬래시 후보. 그게 없으면 /review로 시작.

CALL · 호출 흐름

평소 슬래시처럼 — /myslash

파일 만들면 자동 인식. claude 재시작 필요 X. 기존 /help · /usage 옆에 본인 슬래시가 같이 등장.

자동완성입력 중 / 치면 본인 슬래시도 자동완성 후보
인자/review src/ 처럼 추가 정보 전달
팀 공유git에 커밋하면 모든 팀원이 같은 명령

DEFINITION · Skill이 뭔가

"패키지화된 능력" — Claude에게 새 손기술.

Skill = 특정 작업(PPTX 생성 등)에 필요한 코드·프롬프트·도구를 묶어둔 패키지. .claude/skills/에 두면 자동 인식.

공식Anthropic 공식 — github.com/anthropic/skills
설치git clone 또는 다운로드 → .claude/skills/
사용"PPTX로 만들어줘" — Claude가 자동으로 Skill 호출
CATALOG · 4 공식 Skill

대표 4가지 — PPTX · DOCX · XLSX · PDF

PPTX

슬라이드 자동 생성

"이 데이터로 PPT 만들어줘" → 슬라이드 한 세트. 오늘 실습에서 사용 ★.

DOCX

Word 문서

"보고서 형식으로" → 표·헤딩·스타일 포함 .docx. 회사 보고서 작성.

XLSX

Excel 데이터

"이 JSON을 Excel로" → 시트 + 차트 + 피벗. 데이터 정리.

PDF

PDF 텍스트 추출

"이 PDF 요약해줘" → 텍스트·표 추출 후 분석. 논문·계약서 처리.

실습에서는 PPTX 한 개만. Day 1 자기소개 → 슬라이드로 변환 (5일 내내 재활용 약속의 일부).

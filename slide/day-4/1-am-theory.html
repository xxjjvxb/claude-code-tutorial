PART A · SUB-AGENTS

Sub-agents — 전문가 군단

한 세션에서 모든 일을 다 시키지 말고, 역할별로 분리해서 호출. 컨텍스트가 깨끗해지고 모델 선택까지 가능.

/agents관리 명령
.md1 파일 = 1 에이전트
WHY · 왜 분리하나

메인 세션의 컨텍스트를 깨끗하게 유지.

테스트 작성처럼 토큰 많이 쓰는 작업을 메인에서 하면 메인 컨텍스트가 더러워짐. Sub-agent로 위임 → 결과만 메인에 돌아옴.

컨텍스트Sub-agent가 끝나면 그 작업의 토큰은 메인에 누적 X
모델각 에이전트가 다른 모델 (테스트는 Haiku로 빠르게 등)
역할"테스트 전담" "문서 전담" 같은 명확한 책임
DEFINITION · .md 한 파일

에이전트 1개 = 마크다운 1 파일

.claude/agents/test-writer.md
---name: test-writerdescription: 새 함수·클래스에 pytest 테스트를 작성하는 전담model: haikutools: Read, Write, Edit, Bash---# 역할- 새로 추가된 함수·클래스를 발견하면 tests/ 폴더에 pytest 테스트를 작성- 기존 패턴을 따라 conftest.py 활용- happy path + 에지 케이스 1개씩# 룰- 기존 코드는 절대 수정 X (테스트만 추가)- 한국어로 docstring

상단 frontmatter (---로 둘러싼 부분)에 메타데이터, 본문에 역할/룰. 이 파일이 곧 에이전트의 CLAUDE.md.

USAGE · 호출하기

두 가지 호출 방법 — 자동 또는 명시적

자동 호출 (권장)

메인 Claude가 description을 보고 적절할 때 자동으로 위임.

  • "새 함수 짰어. 테스트도" → test-writer 자동
  • "README 정리" → doc-helper 자동
  • 사람이 명시할 필요 X

명시적 호출

"이 일은 꼭 그 에이전트가" 라고 강제하고 싶을 때.

  • @test-writer 이 함수에 테스트
  • 대화 중 @ 멘션처럼 사용
  • 학습용 / 디버깅용

처음엔 명시적으로 — 어떤 에이전트가 어떻게 동작하는지 손에 익은 후 자동에 맡김.

PART B · MCP

MCP — Claude의 USB 포트

Model Context Protocol. 외부 도구·데이터를 Claude에게 한 줄로 연결하는 표준. Filesystem · GitHub · 검색 · DB 등.

claude mcp add연결 명령
100+공식 MCP 서버
METAPHOR · USB 포트

한 번 꽂으면 Claude가 그 도구를 다룰 수 있게 됩니다.

USB-C가 노트북·핸드폰·헤드폰을 다 연결하듯, MCP는 Claude와 외부 도구의 표준 인터페이스.

전각 도구마다 다른 API · 다른 인증 · 다른 코드
후claude mcp add <server> 한 줄로 통일
예Filesystem · GitHub · Slack · Notion · Google Drive ...
CONNECT · claude mcp add

한 줄로 끝 — claude mcp add

PowerShell — MCP 추가 한 사이클
# 1) 현재 등록된 MCP 보기PS> claude mcp list No MCP servers configured.# 2) Filesystem 서버 추가 (현재 폴더 한정)PS> claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem . ✓ filesystem 서버 등록# 3) 다시 확인PS> claude mcp list · filesystem (npx ...)# 4) Claude 재시작 후 자동 연결

claude 안이 아니라 밖에서 PowerShell로 등록. 등록 후 claude 재시작하면 자동 연결.

USAGE · 연결 후 사용

claude · Filesystem MCP 사용
# 평소 @ 멘션과 비슷하지만 더 강력> logs/ 폴더의 모든 .log 파일에서 ERROR 라인만 모아서 요약해줘 ⚠ Claude wants to use: filesystem.search → Allow once ✓ logs/에서 23개 .log 검색 ✓ ERROR 라인 187개 발견 주요 패턴 3가지: 1. DB 연결 타임아웃 (54회) 2. 인증 실패 (89회) 3. 메모리 부족 (44회)

@ 멘션이 "한 파일 하나 보여주기"라면 MCP는 "폴더 통째로 검색·요약" 같은 큰 작업.

COMPARE · Sub-agent vs MCP

언제 어떤 걸 — 차이

Sub-agent

Claude의 분신

  • 역할별 분리 — 컨텍스트 깨끗
  • 모델 선택 (Haiku · Sonnet · Opus)
  • 같은 도구 사용 (Read · Write · Bash)
  • Claude 안의 일
MCP

외부 세계 연결

  • 외부 도구·데이터 추가
  • 모델 선택 X (메인 Claude가 사용)
  • 새 능력 추가 (DB · GitHub 등)
  • Claude 밖 → 안

정리: Sub-agent = 사람을 늘리고, MCP = 도구를 늘림. 둘은 서로 보완 — 같이 쓰면 강력.

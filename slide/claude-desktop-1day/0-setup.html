WHY · 무엇이 다른가

대화형 AI가 조언자라면 — 이건 실무자

기존 챗봇 — 똑똑한 조언자

"이렇게 하세요"라고 알려 주지만, 실제 일은 내가 합니다. 답을 받아 복사해서 직접 옮겨야 하죠. 내가 직접 답을 옮기던 시대.

Cowork — 똑똑한 실무자

Cowork(Claude 데스크톱 앱 안의 'AI에게 일 맡기기' 기능)는 내 컴퓨터의 파일과 폴더를 직접 열고, 만들고, 정리합니다. 결과물을 손에 쥐여 줍니다. AI에게 시키는 게 동료에게 부탁하는 것과 같은 의미가 됐다 — 그래서 내가 확인하고 OK하는 것의 의미도 같아진다.

도구의 변화가 아니라 — 위임 패턴의 변화.

오늘 실습은 기본 모델(Opus) 그대로면 충분합니다. 모델 이름이 보이면 "일꾼 등급이구나" 정도만 — 바꿀 일은 거의 없습니다.

SETUP · 셋업

시작 준비 — 앱 하나면 끝

세 단계만 따라오면 됩니다. 초대 · 설치 · 첫 실행. 천천히, 한 사람도 빠짐없이 함께 진행합니다. (메일 제출은 표지 안내대로 이미 끝났죠?)

STEP 1 · 초대 · 로그인

초대장 수락 → Claude 로그인

1

메일함에서 초대장을 엽니다.

2

"수락(Accept)"을 누릅니다.

3

제출한 메일로 로그인합니다.

4

이제 같은 팀에서 함께 쓸 준비 끝.

초대장이 안 보이면 스팸함도 확인해 주세요. 메일이 영어여도 당황 금지 — "Accept" 버튼 하나만 누르면 됩니다. 로그인 중 6자리 인증코드 메일이 한 통 더 올 수 있어요 (그 숫자를 그대로 입력).

STEP 2 · 설치

데스크톱 앱 설치 — 받아서 실행

1

채팅방에 공지된 링크에서 Windows용 설치 파일을 받습니다.

2

받은 파일을 더블클릭해 설치합니다.

3

설치가 끝나면 앱을 엽니다.

설치할 건 이 앱 하나뿐입니다. 그 외 다른 프로그램은 필요 없습니다.

STEP 3 · 첫 실행

앱을 열고 — 워크스페이스를 준비한다

워크스페이스(오늘 쓸 실습 재료 폴더) 받기

채팅방의 실습자료.zip을 — 폰이 아니라 PC 브라우저로 채팅방에 들어가 받습니다 → 받은 파일에 오른쪽 클릭 → "압축 풀기". 여기까지만 — 이 폴더를 Cowork에 연결하는 건 다음 장(새 프로젝트)에서 합니다.

권한 — 꼭 기억할 것

Cowork은 이 폴더의 파일을 직접 다룹니다. 워크스페이스 폴더 안에서만 일하니 안전합니다. 중요한 원본 폴더는 절대 작업 폴더로 지정하지 마세요.

압축 푼 위치만 기억해 두세요 — 다음 장에서 바로 찾아갑니다. 바탕화면이 OneDrive 동기화 중인 PC라면 문서 폴더 권장(동기화 충돌 방지). 회사 PC에서 설치가 막히면 손 들어주세요.

NEW PROJECT · 사이드바

Cowork에서 — 새 프로젝트 만들기

왼쪽 메뉴에서 시작

왼쪽 사이드바의 Projects를 클릭 → 화면 가운데 또는 오른쪽 위의 New project 버튼을 누릅니다.

프로젝트 = Cowork이 작업할 폴더 하나 + 대화·기억의 경계. 프로젝트가 바뀌면 이전 대화도, "기억해 둬" 한 것도 새로 시작입니다 — 그래서 오늘은 워크스페이스 전체로 하나만 만들고, 단계는 폴더만 옮겨가며 진행해요.

다른 두 옵션(가져오기 / 기존 폴더 사용)은 이미 만들어 둔 프로젝트나 폴더가 있을 때 쓰입니다.

이름과 — 폴더 위치를 정한다

두 칸만 채우면 끝

이름에 알아볼 만한 제목(예: 클로드 코워크 실습). 프로젝트 위치에는 압축 푼 실습자료 폴더 전체(루트)를 골라줍니다. 끝나면 만들기.

오늘은 실습자료 전체를 한 프로젝트로 둡니다. 채점(/채점)과 단계 간 파일 참조가 이 폴더 기준이라, 하위 폴더로 따로 만들면 안 됩니다. 단계 이동은 "이제 02-보고서 폴더에서 작업하자"라고 말하면 끝.

각 폴더에 목표.md + 끝나면 /채점

폴더를 열면 이번 단계 목표·기준이 적힌 목표.md가 있습니다. 결과물을 만든 뒤 "/채점"이라고 말하면 — Cowork이 그 기준대로 점수표(채점결과.md)를 만들어 줍니다.

⚠️ 조심 첫 대화에서 폴더 접근을 허용한 순간 — 그 폴더의 모든 파일이 AI에게 노출. 작업 폴더는 항상 "공개해도 되는" 파일만. 워크스페이스가 그래서 안전한 출발점.
💡 가져갈 것 AI가 "내 폴더의 파일을 본다"는 사실 자체가 데이터 거버넌스의 새 영역. 평소 모르고 쓰던 폴더의 정보가 곧 AI 컨텍스트(AI가 일할 때 참고하는 정보)가 됨. (T7 패턴 6과 연결.)

슬라이드의 프롬프트(AI에게 보내는 지시문)는 오른쪽 위 "복사" 버튼으로 그대로 가져다 붙이면 됩니다.

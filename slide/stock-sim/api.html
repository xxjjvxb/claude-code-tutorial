가상 시장 API 문서

7장 데스크톱 실습 — 내 트레이딩 앱이 대화할 시장 서버의 전체 명세입니다.

Base URL https://vibecoding-cc.vercel.app/api/stock 인증 헤더 X-API-Key: 내키 (키 발급) ⬇ Claude용 api.md 내려받기 — 프로젝트 폴더에 넣고 @api.md

시장 규칙

종목 · 자금A(1만원대) · B(2.5만원대) · C(500원대) — 시작 자금 1,000,000원
제한수수료 없음 · 공매도 없음(보유량만 매도) · 잔고 초과 매수 불가
속도시세는 초 단위 갱신 — 조회 1초 1회면 충분 · 주문은 키당 1초 1회(초과 시 429)
슬리피지체결가 = 현재가 × (1 ± min(0.05% × 수량, 5%)) — 매수는 비싸게, 매도는 싸게
임팩트내 주문이 시장 가격을 실제로 움직이고 몇 분에 걸쳐 원위치
새 라운드수업 시작 시 관리자가 시장 초기화(전원 100만 · 체결 삭제 · 새 시세) — 키는 그대로 사용

엔드포인트

GET/price

3종목 현재가·거래량 — 1초마다 폴링하는 앱의 심장.

샘플 요청
GET https://vibecoding-cc.vercel.app/api/stock/price
X-API-Key: 내키
샘플 응답
{
  "t": 1787159288,
  "quotes": [
    {"symbol": "A", "price": 10234.5, "volume": 57},
    {"symbol": "B", "price": 25453.2, "volume": 43},
    {"symbol": "C", "price": 501.8, "volume": 66}
  ]
}
GET/history?symbol=A&seconds=600

최근 N초 시세 — 차트 그리기용. 길게 요청하면 포인트가 자동 압축됩니다.

파라미터값설명
symbolA / B / C종목 (필수)
seconds10 ~ 3600과거 몇 초까지 (기본 600)
샘플 요청
GET …/api/stock/history?symbol=A&seconds=300
X-API-Key: 내키
샘플 응답
{
  "symbol": "A",
  "series": [
    {"t": "2026-08-20T02:00:00+00:00", "price": 10201.1, "volume": 52},
    {"t": "2026-08-20T02:00:01+00:00", "price": 10203.4, "volume": 48}
  ]
}
POST/order

시장가 주문 — 응답에 체결 결과와 갱신된 계좌가 함께 옵니다. 키당 1초 1회.

본문 필드값설명
symbolA / B / C종목
sidebuy / sell매수 / 매도
qty1 ~ 10000수량 — 클수록 슬리피지 불리
샘플 요청
POST …/api/stock/order
X-API-Key: 내키
Content-Type: application/json

{"symbol": "A", "side": "buy", "qty": 10}
샘플 응답 — 체결 성공
{
  "filled": 10,
  "exec_price": 10259.1,
  "slippage_pct": 0.5,
  "cash": 897409,
  "pos_a": 10,
  "pos_b": 0,
  "pos_c": 0
}
실패 응답 4가지 — 앱이 대비해야 할 것
상태응답언제
429{"error":"rate limit: 1 order per second"}1초에 2번 주문
400{"error":"not enough cash (need 102591, have 50000)"}잔고 부족
400{"error":"not enough position (have 3)"}보유보다 많이 매도
401{"error":"invalid api key"}키 오류
GET/portfolio

내 계좌 — 현금·보유·평가액·수익률·최근 체결 20건(최신순).

샘플 요청
GET …/api/stock/portfolio
X-API-Key: 내키
샘플 응답
{
  "name": "김서연",
  "cash": 897409,
  "pos_a": 10, "pos_b": 0, "pos_c": 0,
  "value": 1000139,
  "pnl_pct": 0.01,
  "trades": [
    {"t": "2026-08-20T02:35:26+00:00", "symbol": "A",
     "side": "buy", "qty": 10, "price": 10259.1}
  ]
}

value = 현금 + 보유 평가액 · pnl_pct = 수익률(%)

앱 만들 때 팁

시세 폴링 1초 · 차트 갱신 2~3초 · 계좌 갱신 5초면 충분합니다. 통신은 백그라운드 스레드에서 — GUI가 얼지 않게. 주문 버튼엔 앱에서도 연타 방지(1초 1회)를 걸어두면 429를 안 봅니다.

이 문서와 같은 내용의 api.md를 프로젝트 폴더에 넣고 Claude에게 @api.md로 보여주면 — 앱이 나옵니다.

6. **첫 실행 (15′)**: 빈 `Day1/` 폴더에서 `claude` → "안녕하세요" → `/exit` `/help`
7. **VS Code 통합 (10′)**: VS Code에서 같은 폴더 열고 통합 터미널에서 `claude`

> 막힌 사람은 **점심시간 TA가 보충**. 강사는 진도를 끌고 간다.

## 8. Day 2 · 문법 (화)

### 이론 ① — Git 아주 기본 + Claude Code 4대 문법 (90′)

**Part A. Git 아주 기본 + GitHub 가입 (25′)**

- 왜 Git인가 — AI가 파일을 마음대로 고치는 시대일수록 **버전 관리가 안전벨트**
- Git vs GitHub 개념 구분
- **GitHub 계정 가입 (5′)** — github.com에서 그 자리에서
- 핵심 흐름 4개: `init` → `status` → `add` → `commit`
- 되돌리기 한 줄: `git restore <file>` (Day 5 복구 훈련 예고)
- `clone`은 Day 3 텍스트 게임 받아올 때 자연스럽게 등장

**Part B. Claude Code 4대 문법 (65′)**

- `/` 슬래시 커맨드 카탈로그 (`/init` `/clear` `/usage` `/model` `/agents` `/help`)
- `@` 파일 · 폴더 · 심볼 멘션
- `!` 셸 실행 (세션 안에서, PowerShell) — `!git status` 같은 즉석 호출
- `#` CLAUDE.md 즉시 메모

### 실습 ① — Git + 4문법 손풀이 (75′)

- 어제 폴더에 `git init` → 상태 변화 관찰 → 첫 커밋
- `/`로 모델 바꿔보기
- `@`로 어제 만든 HTML 멘션해 분석 시키기
- `!git status` / `!git log` 로 셸 실행 체험 — **권한 물어보면 일단 yes, 자세한 건 오후에**
- `#`로 "한국어로 응답" 메모 추가
- Claude에게 "지금까지 작업 커밋해줘" 시켜 보기

### 점심 — 미니프로젝트 1:1 결정 (60′)

- 강사가 식사 중 1인 5분씩 라운드 → 10명 50분
- 후보 2개 중 난이도 조정해서 결정
- 결정된 주제 단톡방에 공개 → 다른 수강생 자극

### 이론 ② — 모드 · 권한 · 비용 · 컨텍스트 관리 (90′)

- 4 모드: Interactive / Auto / Plan / Bypass
- `Shift + Tab` 모드 전환 / `--dangerously-skip-permissions` 경고
- 권한 확인: "always allow 무지성 금지" 1줄 규칙
- 컨텍스트 윈도우 · 토큰 · `/usage` 습관
- "작은 단위로 잘라 시키기" 원칙
- **세션·컨텍스트 관리**: `/clear` `/compact` `/resume` `--continue` — 비용 절약과 직결

### 실습 ② — 미션 분할 빌드 (105′)

- **미션 ①** 가위바위보 CLI (뼈대→입력→기록 분할)
- **미션 ②** 단위 변환기 (cm↔inch, kg↔lb)
- **선택 보너스** (먼저 끝낸 사람용): 가위바위보 5판 통계+그래프 / 변환기 GUI
- 매 미션 끝마다 `/usage`

## 9. Day 3 · 협업 (수)

### 이론 ① — Plan Mode + Hooks (90′)

**Part A · Plan Mode 깊게 (45′)**

- 안전벨트로서의 Plan Mode (`Shift + Tab`)
- 계획 읽기 → 승인 · 수정 · 거절
- 써야 할 때 vs 굳이 안 써도 될 때

**Part B · Hooks (45′)**

- 이벤트 6종 카탈로그: PreToolUse / PostToolUse / Stop / UserPromptSubmit / Notification / SubagentStop
- **외울 필요 X — 오늘은 Stop 하나만**
- 활용 패턴: 저장 시 lint, 커밋 전 테스트, **응답 끝 → Telegram 알림 (대표 시연)**
- "처음엔 2~3개만" 원칙

### 실습 ① — Plan + Telegram 알림 Hook (75′)

- 오픈 텍스트 게임 다운로드 → Plan Mode로 **분석만** 시키기
- 체력 시스템 추가 (Plan 승인 후 실행)
- **Telegram 알림 Hook 직접 만들기**:
  1. 모바일에 **Telegram 앱 설치 + 가입** (5′)
  2. BotFather 검색 → `/newbot` → 토큰 받기
  3. 본인 봇과 대화 시작 → `getUpdates` API로 chat_id 확보
  4. `.claude/settings.json`의 Stop 훅에 **`curl.exe` 또는 `Invoke-RestMethod`** 한 줄 등록 (PowerShell 기본 `curl`은 alias라 주의)
  5. 짧은 명령 실행 → 휴대폰 알림 확인

### 이론 ② — CLAUDE.md + CoT + .claude 폴더 + Karpathy (90′)

- CLAUDE.md 좋은 예 vs 나쁜 예 (200줄 룰)
- 계층: 프로젝트 / 유저(`~/.claude`) / 엔터프라이즈
- CoT 유도: `think` < `think hard` < `think harder` < `ultrathink`
- 메타 프롬프트 / 자기 검증 요구
- **`.claude` 폴더 구조 한눈에**: `commands/` `agents/` `hooks/` `skills/` `settings.json` `CLAUDE.md`
- **신호 vs 잡음 원칙** — CLAUDE.md는 길이가 아니라 신호만 남기고 잡음은 빼라 (30줄이 300줄보다 잘 작동)

### 실습 ② — 복구 + 내 CLAUDE.md + 미니프로젝트 첫 손대기 (105′)

- **(45′)** 일부러 망가뜨린 코드 복구 — 에러 메시지 그대로 전달, Claude에게 디버깅 시키기
